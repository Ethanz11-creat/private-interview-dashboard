需要保留的版本差异

  • Kimi-K2-Instruct 初版官方配置与 README 为 128K，原画板标 256K；正文没有将后续更新版本长度套给初版。
  • DeepSeek V3.2 GitHub README 介绍 V3.2-Exp；正式 V3.2 的结构数值另按发布配置核对。两者后训练与性能数据不混用。
  • Qwen3 初版 235B-A22B 配置 max_position_embeddings 为 40960；配置值、官方长上下文扩展方案与 2507 更新版分开说明。
  • Step 3.5 Flash 的 3:1 是层类型周期，45 层末尾周期截断；SWA 与全注意力 head 数量并不相同。
  • Qwen3.5-397B-A17B 图展示语言主干；完整模型还有视觉编码器。重绘补入配置中 Top-10 与共享专家字段。
  • DeepSeek V3 主模型 671B 与额外 MTP 权重分开；R1 蒸馏版本采用各自学生模型结构。
  • MiniMax 230B / 10B 为原画板的规模口径；62 层、GQA、QK Norm、Top-8 与无共享专家均另核发布配置。
  • JEV 只保留厂商公开定位和明确标记的通用系统解释；没有绘制或推断其内部神经网络。
