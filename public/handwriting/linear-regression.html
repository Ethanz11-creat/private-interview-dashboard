01 / 练习前先看这一段

P4484. 线性回归（最小二乘法）

难度：5。以下题干与约束整理自你提供的题面；网页尝试次数、通过次数不参与算法要求。

题目描述

实现一元线性回归，使用最小二乘法求解 y = wx + b。给定训练样本点集合 points，其中每个元素为 [x, y]，请计算并返回拟合得到的参数 w 和 b。

输入参数

points：二维列表，每个元素为长度为 2 的浮点数列表 [x, y]，表示一个训练样本点。

返回值

[w, b]：长度为 2 的列表，分别为拟合直线的斜率 w 和截距 b，可按浮点数形式返回。

示例 1

输入：
points = [[1.0, 2.0], [2.0, 4.0], [3.0, 6.0],
          [4.0, 8.0], [5.0, 10.0]]

输出：
[w, b] = [2.0000, 0.0000]

数据范围与保证

  • 1 ≤ len(points) ≤ 5 × 10⁴。
  • −10⁵ ≤ x, y ≤ 10⁵。
  • 至少存在两个不同的 x 值。
最后一条是关键：它保证分母 Σ(xᵢ−x̄)² 大于 0。虽然给出的数量范围从 1 开始，但满足“两个不同 x”也意味着实际有效输入至少有两个点。

题面给出的闭式解

w = ∑ᵢ (xᵢ − x̄)(yᵢ − ȳ)∑ᵢ (xᵢ − x̄)²
b = ȳ − w x̄

x̄ 是所有 x 的均值，ȳ 是所有 y 的均值。目标是返回两个参数，不是预测某一个新点，也不是返回整条直线上的坐标。

02 / 把公式和变量一一对应

先算平均位置，再算每个点偏离多少

变量形状 / 类型原题示例
data(n,2)，二维浮点数组每行一个 [x,y] 点。
X / Y(n,)，一维数组X=[1,2,3,4,5]；Y=[2,4,6,8,10]。
mean_x / mean_y两个标量x̄=3，ȳ=6。
dx / dy(n,)，一维数组dx=[−2,−1,0,1,2]；dy=[−4,−2,0,2,4]。
num一个标量偏差乘积之和：8+2+0+2+8=20。
den一个标量x 偏差平方之和：4+1+0+1+4=10。
w / b两个标量w=20/10=2；b=6−2×3=0。
先求均值

找到数据的平均位置 (x̄,ȳ)。

再算偏差

每个 x、y 分别减自己的均值。

最后累加求解

偏差乘积之和除以 x 偏差平方之和，再求截距。

记公式可以这样读：“w 的分子是 x 偏差乘 y 偏差再求和，分母是 x 偏差平方再求和；b 是 y 均值减 w 乘 x 均值。”不要把分母写成 dy²。

04 / 按代码顺序展开数值

每个数组、每次求和，都能对上表格

这三句分别在做什么？

dx = X - mean_x        # 每个 x 都减去同一个 x 均值
num = np.sum(dx * dy)  # 对应元素相乘，再把全部乘积相加
den = np.sum(dx * dx)  # 每个 dx 乘自己，再把全部平方相加

数组减标量：为什么只写一次？

NumPy 会把标量广播到数组的每一项。例如 [1,2,3,4,5] − 3 得到 [−2,−1,0,1,2]。普通 Python 列表不能直接这样减，要用循环或列表推导式。

dx * dy 不是矩阵乘法

对 NumPy 数组，* 表示对应元素相乘。例如 [−2,−1] * [−4,−2] 得到 [8,2]。再用 np.sum 才得到总和 10。

这里 np.sum(dx * dy) 对一维数组所有元素求和，不需要额外指定 axis。

分子为什么可能为负？dx 和 dy 的符号可以相反，所以乘积及总和可能为负，w 也可能为负。分母是平方和，至少两个不同 x 保证它严格大于 0。
05 / 理解最小二乘在“最小”什么

最小化的是纵向误差的平方和

真实值是 yᵢ，预测值是 ŷᵢ = wxᵢ+b。残差是 yᵢ − ŷᵢ；最小二乘让 ∑(yᵢ−ŷᵢ)² 最小。橙色竖线表示残差，不是点到直线的垂直最短距离。

上面的数据选择会同步改变这里的图。你可以输入其他 w、b，比较平方误差；“恢复最小二乘解”会回到代码求得的参数。

训练点当前直线纵向残差
为什么 b = mean_y − w * mean_x？

带截距的一元最小二乘直线经过平均点 (x̄,ȳ)。把这个点代入 ȳ = w x̄ + b，移项就得到 b = ȳ − w x̄。

比如 x̄=3、ȳ=6、w=2，就有 b=6−2×3=0。

想知道 w 的公式从哪里来？可以看这段简短推导

目标函数是 L(w,b)=∑(yᵢ−wxᵢ−b)²。对 b 求导并令其为 0，得到 ∑(yᵢ−wxᵢ−b)=0，因此 b=ȳ−wx̄。

代回去，每个残差变成 (yᵢ−ȳ)−w(xᵢ−x̄)。对 w 求导并令其为 0，得到 ∑(xᵢ−x̄)(yᵢ−ȳ) = w∑(xᵢ−x̄)²。

分母非零，除过去就是代码中的 w 公式。你手撕时主要要能把公式对应到变量和累加过程。

最小二乘是不是必须穿过每个训练点？

不是。原题示例恰好都在 y=2x 上，所以误差能为 0。切换到“带噪声的三个点”时，最优直线也有非零残差，只是所有可能的 w、b 中平方误差最小。

06 / 不依赖 NumPy 的完整对照

两遍循环，额外空间 O(1)

class Solution:
    def linear_regression(self, points):
        n = len(points)
        sum_x = 0.0
        sum_y = 0.0
        for x, y in points:
            sum_x += x
            sum_y += y

        mean_x = sum_x / n
        mean_y = sum_y / n

        num = 0.0
        den = 0.0
        for x, y in points:
            dx = x - mean_x
            dy = y - mean_y
            num += dx * dy
            den += dx * dx

        w = num / den
        b = mean_y - w * mean_x
        return [w, b]

for x, y in points 把每个 [x,y] 解包成两个变量。第一遍只求总和和均值，第二遍逐点求偏差并累加；不创建 X、Y、dx、dy 数组。

NumPy 的逐元素运算

dx = X - mean_x
dy = Y - mean_y
num = np.sum(dx * dy)
den = np.sum(dx * dx)

dx、dy 是长度为 n 的数组；NumPy 一次处理全部元素。

普通循环的逐点累加

num = 0.0
den = 0.0
for x, y in points:
    dx = x - mean_x
    dy = y - mean_y
    num += dx * dy
    den += dx * dx

dx、dy 是当前点的两个标量；每次循环更新同一组变量。

两种实现的复杂度分别是什么？

实现时间额外空间为什么
你贴的 NumPy 版本O(n)O(n)data、dx、dy 以及逐元素乘法结果都有随 n 增长的存储。
上面的普通循环版本O(n)O(1)只保留固定数量的均值、累加值和当前点变量。
为什么两遍循环仍然是 O(n)？第一遍 n 次，第二遍 n 次，共约 2n 次，忽略常数 2 后仍然是 O(n)。空间看同时需要多少存储位置，不是看循环执行了多少次。

X 和 Y 通常是 data 的列切片视图，本身不必各复制一整列；但 data 已经是新建的 n×2 数组，dx、dy 和乘法结果也要存储，整体仍是 O(n)。

07 / 从看懂到盲写

先背计算顺序，再写具体语法

  1. 取列：data[:,0] 是 X，data[:,1] 是 Y。
  2. 求均值：mean_x=np.mean(X)，mean_y=np.mean(Y)。
  3. 算偏差：dx=X−mean_x，dy=Y−mean_y。
  4. 求两项和：num=sum(dx×dy)，den=sum(dx×dx)。
  5. 求参数：w=num/den，b=mean_y−w×mean_x。
  6. 返回：[float(w),float(b)]。

复盘 1：冒号与 0 各代表什么？

X = data[:, 0]

查看答案
冒号选择所有行，0 选择第 0 列，也就是所有点的 x。输出形状 (n,)，不是 (n,1)。

复盘 2：分母为什么不是 dy * dy？

本题拟合 y = wx+b。

查看答案
w 是 y 对 x 的斜率，闭式解的分母是 x 偏差平方和。把它换成 y 偏差平方和是在改变公式。

复盘 3：至少两个不同 x 有什么用？

den = Σ(xᵢ−x̄)²

查看答案
每项都是非负数；两个不同 x 意味着不可能全等于 x̄，因此至少一项大于 0，den>0，不会除以 0。

复盘 4：普通循环里 dx 占多少空间？

dx = x - mean_x 每轮执行一次。

查看答案
它只是当前点的一个标量，循环中反复更新，O(1)。NumPy 的 dx=X−mean_x 却保存 n 个偏差，O(n)。

返回浮点数为什么没有四个尾随零？

题目允许按浮点数返回，不要求把参数变成字符串。返回 2.0 与展示 2.0000 是同一个数。只有打印文本需要固定四位小数时，才用 f"{w:.4f}"；计算途中不要提前 round。
