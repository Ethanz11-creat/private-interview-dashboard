01 / 原题整理

题干、输入与输出

难度：5。给定序列 \(X\in\mathbb{R}^{T\times d_{\mathrm{model}}}\)、线性投影权重与偏置、Query head 数 \(h_q\)、Key / Value head 数 \(h_k\) 和输出投影，请实现 Grouped Query Attention（GQA），返回二维浮点列表 \(O\)。

要求 1 ≤ h_k < h_q、d_model % h_q == 0、h_q % h_k == 0。每头维度由 Query 头数决定：d_k = d_model // h_q。K 与 V 只有 h_k * d_k 列，而不是 d_model 列。

约束与计算范围

  • 输入元素：−1000 ≤ X[i,j] ≤ 1000。
  • 所有权重元素：−10 ≤ W_Q、W_K、W_V、W_O ≤ 10。
  • 所有偏置元素：−5 ≤ b_Q、b_K、b_V、b_O ≤ 5。
  • Softmax 沿 Key 位置归一化；每个 head、每个 Query 的一行权重和为 1。

02 / 先理解分组

多个 Query head，共享一个 K/V head

接着多头注意力的拆头过程看：每个 Query head 仍然包含全部 T 个 token，每个 head 的特征维度仍是 d_k。变化发生在 K/V 投影上——用更窄的 W_K、W_V，直接生成较少的 K/V 特征组。

本题 h_q=2、h_k=1：Q_0 和 Q_1 都读取 K_0、V_0 的全部 token。Q_0 与 Q_1 的向量不同，所以会分别计算不同的 scores、Softmax 和 H。共享 K/V 不等于共享注意力权重，也不会把两个 Query head 合成一个。
形式Query 头数K/V 头数对应关系
MHAh_qh_q每个 Q_i 使用自己的 K_i、V_i
GQAh_q通常 1 < h_k < h_q每组 s=h_q/h_k 个 Query 共享一组 K/V
MQAh_q1全部 Query 共享唯一的一组 K/V

本题允许 h_k=1，因此原题样例是 GQA 通式的 MQA 特例。h_k=h_q 可退化为 MHA，虽然不属于本题严格的 h_k<h_q 范围，也有助于理解三者的关系。

这个选择器只改变共享结构示意。下方的数值演示固定使用原题 h_q=2、h_k=1 和对应权重，避免换头数后仍错误复用原来的投影矩阵。

索引规则：为什么是整除？

s = hqhk
g(i) = \left\lfloor is \right\rfloor

从 0 开始编号。若 h_q=8、h_k=2，每组有 4 个 Query：i=0、1、2、3 的 i//4 均为 0；i=4、5、6、7 的结果为 1。i % h_k 会生成 0、1、0、1… 的交错映射，不是题目要求的连续分组。

03 / 公式对应代码

六步完整计算

1. 线性投影：K/V 的输出维度更窄

Q = XWQ + bQ
K = XWK + bK
V = XWV + bV

Q 的形状是 (T,d_model)，K、V 的形状是 (T,h_k×d_k)。各投影仍读取每个 token 的全部原始 d_model 维输入；不是先把 X 切小，也不是先生成完整的 K/V 再删掉某些头。

2. 拆 Query：h_q 个头

Q.reshape(T, h_q, d_k).transpose(1, 0, 2)
# (T, d_model) → (T, h_q, d_k) → (h_q, T, d_k)

3. 拆 K/V：只有 h_k 个头

K.reshape(T, h_k, d_k).transpose(1, 0, 2)
V.reshape(T, h_k, d_k).transpose(1, 0, 2)
# (T, h_k*d_k) → (T, h_k, d_k) → (h_k, T, d_k)

每组里的 Query 都拿到同一个完整的 K/V head。不要把 K_g 再切成 s 个子块：单个 K/V head 已经是 (T,d_k)，要与每个 Q_i 的 d_k 对齐。

4. 每个 Query head 单独算注意力

Si = QiKg(i)T√d_k
Ai = \operatorname{softmax}(Si)
Hi = AiVg(i)

Q_i、K_g、V_g 均为 (T,d_k)。Q_i @ K_g.T 得到 (T,T)，行表示 Query token，列表示 Key token。对每行做 Softmax 后，A_i @ V_g 得到 (T,d_k)。缩放使用 √d_k，不是 √d_model，也不是 √h_k。

5. 拼接全部 Query head 的输出

H = \operatorname{concat}(H0,\dots,Hh_q-1)
hqdk = dmodel

总共有 h_q 个输出头，所以同一个 token 的所有头沿特征维拼成 d_model 个数。只有 h_k 个 K/V 头，不会把输出宽度变成 h_k×d_k。

6. 输出投影

O = HWO + bO

W_O 混合拼接后的各头特征，输出仍是 (T,d_model)。它不是 Softmax，因此最终输出不必在 0～1 内。

06 / 不只记形状

拆头、共享、拼头与常见语法

1. reshape 与 transpose：数据没有变，只换分组和轴

Q · (token, feature)
[[2,2,1,3],
 [1,1,2,0]]
形状 (2,4)
reshape · (token, head, feature)
[
 [[2,2],[1,3]],  # token 0
 [[1,1],[2,0]]   # token 1
]
形状 (2,2,2)
transpose · (head, token, feature)
[
 [[2,2],[1,1]],  # head 0
 [[1,3],[2,0]]   # head 1
]
形状 (2,2,2)

本例 token 数和 head 数都等于 2，因此换轴前后形状恰好都是 (2,2,2)，但每个下标的语义与元素排列已经改变。换轴后，一个 head 的完整 token 序列才放在一起。

目的NumPyPyTorch
token 轴、head 轴交换transpose(1,0,2)：指定完整新轴顺序transpose(0,1)：交换两个指定轴
每头 K 的矩阵转置循环里的 Ki 是二维，Ki.T 合适Kh 是三维，transpose(-2,-1) 只交换最后两轴

2. repeat_interleave：同一组挨着重复，不能用错 repeat

# 只用 head 标签示意：h_q=8, h_k=2, group_size=4
原始 K/V heads：          [KV0, KV1]
repeat_interleave(4, 0)： [KV0, KV0, KV0, KV0, KV1, KV1, KV1, KV1]
对应 Query heads：        [ Q0,  Q1,  Q2,  Q3,  Q4,  Q5,  Q6,  Q7]

# repeat(4,1,1) 是另一种排列，会错配连续分组：
# [KV0, KV1, KV0, KV1, KV0, KV1, KV0, KV1]

repeat_interleave(group_size,dim=0) 对 head 轴的每一个元素分别连续重复。这个教学实现会物化展开后的 K/V 张量，方便与 Qh 批量相乘；NumPy 循环版则用 Kh[g]、Vh[g] 读取，不复制成 h_q 份。

3. axis=1、keepdims=True 与行广播

NumPy 循环中 scores 是二维 (T,T)，axis=1 表示沿每行的 Key 位置求最大值 / 求和。PyTorch 批量 scores 是 (h_q,T,T)，dim=-1 是最后一维，也就是 Key 位置。这里不归一化 Query 轴或 head 轴。

head 0 的 scores · (2,2)
[[7.071068,2.828427],
 [3.535534,1.414214]]
max(axis=1,keepdims=True) · (2,1)
[[7.071068],
 [3.535534]]
每行减去自己的最大值 · (2,2)
[[0,-4.242641],
 [0,-2.121320]]

scores.max(...) 是数组方法，等价于 np.max(scores,...)；attn.sum(...) 等价于 np.sum(attn,...)。keepdims=True 保留被归约的轴为长度 1，所以 (2,1) 可以逐行广播到 (2,2)。删除它得到 (2,)，这在方阵中可能恰好不报错，却沿列对齐，悄悄减错行。

scores = scores - scores.max(axis=1, keepdims=True)
attn = np.exp(scores)                    # 每项分别取指数
denominator = attn.sum(axis=1, keepdims=True)  # 每行自己的分母
attn = attn / denominator                # 逐行归一化

减最大值不改变 Softmax 的结果，同时避免很大正数的指数溢出。对于有限、无 mask 的得分，每行至少有一项 exp(0)=1，分母不会为 0。正确拼写是 keepdims=True；PyTorch 对应参数叫 keepdim=True，此处 torch.softmax 已完成内部归一化。

4. np.empty：分配空间，还没有算出答案

np.empty((h_q,T,d_k)) 只分配未初始化的数组。for 循环必须写入每一个 Hh[i] 后才能使用。它不等价于全零数组，也不是将空值参与注意力运算。

5. 拼头：先把 token 放回第一轴

# Hh 的顺序是 (head, token, feature)
Hh = [
  [[1,1.014166], [1,1.107042]],  # head 0
  [[1,1.007035], [1,1.195570]]   # head 1
]

# transpose → (token, head, feature)，再 reshape 合并最后两轴
H = [[1,1.014166,1,1.007035],  # token 0：head 0 + head 1
     [1,1.107042,1,1.195570]] # token 1：head 0 + head 1

直接 Hh.reshape(T,d_model) 会把 head 0 的 token 0、token 1 拼到同一行，形状虽然正确，语义却错了。NumPy 的 np.concatenate([H_0,H_1],axis=1) 可得到相同的正确拼接；PyTorch 换轴后用 reshape，会在需要时创建连续拷贝，无须强行改用 view。

07 / GQA 节省什么

主要节省 K/V 投影与 KV Cache

令 M=d_model，d_k=M/h_q。Q 投影与输出投影仍是 (T,M)@(M,M)；K/V 投影变成 (T,M)@(M,h_k d_k)。K/V 投影的参数量与乘法量，相比同样 h_q 的 MHA 按 h_k/h_q 缩小。Query head 数没有减少。

部分工作量 / 元素数是否随 K/V 头数减少
Q、输出投影O(TM²)不减少
K/V 投影O(TM · h_k d_k)比 MHA 缩小 h_k/h_q
全部 Query heads 的得分与加权 VO(h_q T²d_k)=O(T²M)本实现仍计算 h_q 份
显式注意力权重O(h_q T²)不是 h_k T²
推理时每层 K+V 缓存2 × batch × L × h_k × d_k 个数相比 MHA 的 2 × batch × L × h_q × d_k 缩小 h_k/h_q

两份代码的总时间阶仍为 O(TM² + T²M)。计入列表转换产生的权重副本与中间输出：NumPy 循环版额外空间为 O(M² + TM + T²)，因为它每次只保留一头的得分与权重；PyTorch 批量版为 O(M² + TM + h_q T²)，同时计算并保留全部 Query heads 的注意力矩阵。这里的浏览器演示为了展示中间结果，也显式保留了所有头。

缓存压缩 ≠ repeat 后的临时张量压缩。原始缓存可只存 h_k 组 K/V；但本页 PyTorch 教学代码先用 repeat_interleave 展开成 h_q 组，确实会产生较大的临时张量。生产实现可用支持 GQA 的内核按组读取，避免显式复制。GQA 不保证精度毫无损失，也不能据此宣称整个注意力计算量按同一比例缩小。

L 为缓存序列长度、batch 为批大小；换成字节需再乘 dtype 字节数与层数。本题只写完整序列前向，不实现 KV Cache 的增量更新。

08 / 复现检查

投影 → 拆头 → 映射 → 注意力 → 拼头 → 输出

d_k = d_model // ______
group_size = h_q // ______
Qh = Q.reshape(T, h_q, d_k).transpose(______, ______, ______)
Kh = K.reshape(T, ______, d_k).transpose(1, 0, 2)
Vh = V.reshape(T, ______, d_k).transpose(1, 0, 2)
for i in range(h_q):
    g = i // ______
    scores = (Qh[i] @ Kh[______].T) / np.sqrt(______)
    scores -= scores.max(axis=______, keepdims=______)
    attn = np.exp(scores)
    attn /= attn.sum(axis=______, keepdims=______)
    Hh[i] = attn @ Vh[______]
H = Hh.transpose(______, ______, ______).reshape(T, d_model)
O = H @ W_O + b_O
展开关键答案与自检点
  • d_k 用 h_q；group_size 用 h_k。
  • NumPy 换轴顺序是 1,0,2；K/V reshape 使用 h_k。
  • g = i // group_size；Kh[g]、Vh[g]；缩放用 √d_k。
  • 二维逐行 Softmax 使用 axis=1、keepdims=True。
  • 拼头前 transpose(1,0,2)，输出列数始终是 d_model。
  • 只有一个 token 时，各头注意力权重都是 [1]，但不同 KV 组可有不同的 V。
  • 验证非零偏置、多个 KV 组、极大得分和不合法整除条件，避免只靠 h_k=1 的样例判断映射正确。
