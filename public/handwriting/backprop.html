01 / 先解决 y_hat_clipped 后面的疑惑

反向传播不是一串孤立公式，而是一条从 loss 往回走的链

这道题是单个样本、两层全连接、隐藏层 ReLU、输出层 Sigmoid 的二分类网络。前向传播把 x 变成概率，再得到 loss；反向传播从这个 loss 出发，沿着相反方向逐层使用链式法则，得到每个参数的梯度。

青色：前向计算橙色：梯度回传紫色虚线：在节点处分叉生成参数梯度

注意：反向传播的箭头方向与前向相反；每一步都是“已经得到的上游梯度 × 当前节点的局部导数”。参数梯度的形状必须与原参数完全一致，才能执行更新。

① 先处理概率边界y_hat_clipped = clamp(y_hat, ε, 1−ε)

只为后面的 log 防止出现 log(0)，不是重新定义 Sigmoid。

② 计算二分类损失L = −[y log ŷ + (1−y)log(1−ŷ)]

y=1 时是 −log ŷ；y=0 时是 −log(1−ŷ)。一个公式覆盖两种标签。

③ 得到输出误差δ2 = dL/dz2 = ŷ−y

这是 Sigmoid 与 BCE 的导数抵消后的结论；不要再乘 ŷ(1−ŷ)。

④ 先求第二层dW2=δ2·h；db2=δ2

δ2 是标量，乘隐藏向量 h 后得到与 W2 同形状的向量。

⑤ 梯度传到隐藏层dL/dh = δ2·W2

必须使用更新前的旧 W2；否则会把两套参数混在同一次反向传播里。

⑥ 通过 ReLU 闸门δ1=dL/dh·1[z1>0]

z1≤0 的神经元把梯度置零；z1=0 时本实现约定导数为 0。

⑦ 得到第一层梯度dW1=x⊗δ1；db1=δ1

外积把 (d_in,) 和 (d_hidden,) 组合成 W1 的矩阵形状。

⑧ 最后统一更新θ_new = θ_old − lr·dθ

先算完所有旧参数上的梯度，再一次性更新四组参数。

从代码读这条路线

eps = 1e-12
y_hat_clipped = clamp(y_hat, eps, 1-eps)
loss = BCE(y, y_hat_clipped)

# 从这里开始反向
δ2 = y_hat - y
dW2 = δ2 * h
db2 = δ2
dL_dh = δ2 * W2
δ1 = dL_dh * ReLU'(z1)
dW1 = x ⊗ δ1
db1 = δ1

问题 1 · 损失函数“我印象里是一个 −log，为什么这里叫 BCE？”

结论：−log 是 BCE 在某一个标签下的分支；BCE 用一个公式统一 y=0 和 y=1。

输出层 Sigmoid 只输出一个“属于正类的概率” ŷ。当 y=1 时，BCE 变成 −log(ŷ)；当 y=0 时，变成 −log(1−ŷ)。二分类必须同时惩罚“漏掉正类”和“误报正类”，所以代码写成完整的 BCE。多分类才通常使用 Softmax 加多分类交叉熵。

如果网络输出的是 logit z2，工程上可直接用 BCE-with-logits / softplus，避免先算概率再 clip。

问题 2 · 第一层权重“为什么 dW1 不是 dL_dz2 × x？”

结论：第一层权重连接的是 x 到每个隐藏神经元，必须使用已经传到隐藏层的 δ1=dL/dz1，再和 x 做外积。

对每个元素展开：z1[j] = Σᵢ x[i]W1[i,j] + b1[j]，所以 ∂L/∂W1[i,j] = (∂L/∂z1[j])·x[i] = δ1[j]·x[i]。dL_dz2 只是一个标量，乘 x 只能得到 (d_in,)，而 W1 是 (d_in,d_hidden)；还缺少每个隐藏单元自己的梯度。

因此 torch.outer(x, δ1) 生成矩阵：x=(2,) ⊗ δ1=(3,) → dW1=(2,3)。它不是点积，不会把 6 个乘积求和。

问题 3 · 记忆还是推导“dL_dz2 = ŷ−y 直接记就行吗？”

结论：可以记，但要连同前提一起记：Sigmoid 输出 + BCE 损失。

链式法则只有三步：∂L/∂ŷ = −y/ŷ + (1−y)/(1−ŷ)；∂ŷ/∂z2 = ŷ(1−ŷ)；两者相乘后分母抵消，得到 ∂L/∂z2 = ŷ−y。所以这不是“所有损失函数都能套”的口诀。

换成 Sigmoid+MSE 时要多乘 Sigmoid 导数；换成多分类 Softmax+交叉熵时也有类似的“预测−标签”，但标签变成 one-hot 向量。

最容易混淆的一点：y_hat_clipped 只是概率形式 BCE 的数值保护；当前代码的 dL_dz2 = y_hat − y 对应未截断 BCE 的解析梯度。普通概率范围内两者一致；极端值触发 clip 时，建议改用直接接收 z2 的 BCE-with-logits，让损失与梯度严格对应。
01 / 完整题干 · 手撕前先看

P4486. 反向传播（两层全连接网络）

难度：5。以下根据你提供的题面整理，保留全部输入、输出、示例和约束。

题目描述

实现一个两层全连接神经网络：输入层 2 维，隐藏层有 3 个神经元、使用 ReLU 激活，输出层有 1 个神经元、使用 Sigmoid 激活。

给定网络参数 W1、b1、W2、b2，单个输入样本 x=[x1,x2]、二分类标签 y∈{0,1} 和学习率 lr，执行一次前向传播，计算 BCE 损失，再进行一次反向传播，并用梯度下降更新参数。

输入参数

参数规定的形状 / 含义
lr学习率，0<lr≤1。
W12×3 的隐藏层权重；行是输入特征，列是隐藏神经元。
b1长度为 3 的隐藏层偏置。
W2长度为 3 的输出层权重。
b2输出层偏置标量。
x长度为 2 的单个输入样本。
y标签 0 或 1。

前向传播公式

z1 = x @ W1 + b1                 # 三个隐藏线性值
h  = ReLU(z1) = max(0,z1)        # 逐元素
z2 = Σⱼ W2[j] * h[j] + b2        # 一个输出线性值
y_hat = 1 / (1 + exp(-z2))       # 预测标签为 1 的概率
loss = -[y*log(y_hat) + (1-y)*log(1-y_hat)]
题面有一个维度写法不一致：题干部分写了 z1=W1x+b1，但参数规定 W1 为 2×3，x 长度为 2。按给定形状，应写 x @ W1 + b1，或采用列向量记法 W1.T @ x + b1。本页与提供的代码一致，采用 x @ W1。

反向传播与更新要求

求出 loss 对四组参数的梯度，然后统一执行 参数_new = 参数_old − lr × 对应梯度。这里只有一个样本，无需再除以 batch 大小。

返回值

依次返回 (loss, W1_new, b1_new, W2_new, b2_new)。loss 是本次更新之前的前向损失，后四项是一次更新后的参数。

示例 1

输入：
lr = 0.1
W1 = [[0.1, -0.5, 0.3], [0.4, 0.5, -0.6]]
b1 = [0.0, 0.1, 0.0]
W2 = [0.2, -0.1, 0.4]
b2 = 0.0
x = [1.0, 2.0]
y = 1

题面展示的输出（约数）：
loss = 0.63
W1_new = [[0.11, -0.5, 0.3], [0.42, 0.49, -0.6]]
b1_new = [0.01, 0.1, 0.0]
W2_new = [0.24, -0.07, 0.4]
b2_new = 0.05

题面输出是低精度展示。实际 loss≈0.6349461016；计算中保留双精度，不要每一步都按示例舍入。

数据范围与提示

  • 输入和参数均为浮点数，使用双精度计算。
  • 形状固定：W1 为 2×3，b1、W2 长度为 3，x 长度为 2，b2 为标量。
  • 0 < lr ≤ 1；−1000 ≤ x[i] ≤ 1000。
  • −10 ≤ W1[i][j], b1[j], W2[j], b2 ≤ 10。
  • y∈{0,1}。
02 / 先认形状，再认梯度

梯度必须与它要更新的参数形状相同

前向变量形状对应反向变量反向形状
x(2,)本题不要求返回输入梯度—
W1 / b1(2,3) / (3,)dW1 / db1(2,3) / (3,)
z1 / h(3,) / (3,)dL_dz1 / dL_dh(3,) / (3,)
W2 / b2(3,) / 标量dW2 / db2(3,) / 标量
z2 / y_hat / loss均为标量dL_dz2标量
记号怎么读：dL_dz2 就是 ∂L/∂z2，表示“z2 稍微变动时，loss 会如何变化”。变量名里的 d 不是数组长度；它在这里表示导数或梯度。

@、dot、*、outer 是四种不同操作

代码作用输入 → 输出
x @ W1每列两个输入贡献相加(2,) 与 (2,3) → (3,)
np.dot(W2,h)对应乘积相加，点积(3,) 与 (3,) → 标量
dL_dh * mask逐元素相乘，不求和(3,) 与 (3,) → (3,)
np.outer(x,dL_dz1)每个输入与每个隐藏梯度配对相乘(2,) 与 (3,) → (2,3)

04 / 单个样本的完整数值过程

从 0.9、0.6、−0.9，一步走到新参数

以下固定使用题目示例的 x 与初始参数。可切换标签或学习率，对比梯度方向与更新幅度；改变学习率不改变更新前的预测和 loss。

真实标签

H2 的 z1 为负，被 ReLU 关闭。它的 h=0、dL/dz1=0；本样本不会更新 W1 的第 2 列、b1[2] 或 W2[2]。

05 / 公式不是凭空背出来的

每一步都是“上游梯度 × 局部导数”

输出起点dL/dz2 = y_hat−y
传回隐藏dL/dh = (y_hat−y)×W2
通过 ReLUdL/dz1 = dL/dh × 1[z1>0]
生成参数梯度dW1[i,j] = x[i]×dL/dz1[j]

为什么 BCE + Sigmoid 等于 y_hat−y？

先记 p=y_hat。对未截断的 BCE，有 dL/dp = −y/p + (1−y)/(1−p)；Sigmoid 有 dp/dz2 = p(1−p)。

dL/dz2 = [−y/p + (1−y)/(1−p)] × p(1−p) = p−y

两个导数合并后已经简化。因此写了 dL_dz2=y_hat−y，就不要再乘 p(1−p)，否则把 Sigmoid 导数重复算了一遍。

输出层三个方向，分别乘谁？

要求的梯度z2 对该变量的局部导数结果
dW2[j]h[j]dL_dz2 × h[j]
db21dL_dz2
dL_dh[j]旧 W2[j]dL_dz2 × W2[j]
为什么先算梯度再更新？反向传播是在当前这一次前向计算图上求导，所有局部导数都应使用这一次的旧参数。若先把 W2 改了，再用新 W2 算 dL_dh，就混合了两套参数。

ReLU 掩码：不是只看“有没有非零梯度”

z1 = [0.9, 0.6, -0.9]
z1 > 0 = [True, True, False]
mask = [1.0, 1.0, 0.0]

dL_dh  = [-0.094007, 0.047004, -0.188014]
dL_dz1 = [-0.094007, 0.047004, 0.000000]

第三个隐藏输出的上游梯度不为 0，但 ReLU 在这个负输入区域的导数为 0，所以传到 z1 的梯度被截断。

outer 可以展开成两个循环

dW1 = [[0.0] * 3 for _ in range(2)]
for i in range(2):
    for j in range(3):
        dW1[i][j] = x[i] * dL_dz1[j]

np.outer(x,dL_dz1) 正好完成这个配对乘法。它与 dot 的区别在于：每个乘积都保留为矩阵一项，不把乘积加起来。

ReLU 在 z1=0 处的导数到底是多少？

ReLU 在 0 处没有唯一的普通导数。实现时通常选一个约定值；这两份代码用 z1>0 作掩码，因此在 0 处选 0。

梯度下降为什么有些参数会变大？

更新是参数−lr×梯度。梯度为负时，相减会使参数增大；下降指的是朝局部降低 loss 的方向移动，不是每个参数数值都减小。

学习率太大时，一次更新并不保证实际 loss 降低，尤其是网络包含非线性激活时。

06 / 极端值下的正确计算

稳定 Sigmoid 和稳定 BCE 是两件事

稳定 Sigmoid 防止 exp 溢出，但它仍可能在浮点数中得到精确的 0 或 1。原版 clip 避免 log(0)，却会限制可报告的 loss。比如 z2=−1000、y=1，真实 BCE 约为 1000，而 clip(p,1e−12,…) 后只得到约 27.631。

结合本题数值范围：输入可达 ±1000，权重可达 ±10，输出 z2 可能很大。因此如果要求极端输入的真实 BCE，建议直接用 z2 计算稳定损失，而不是只截断概率。原版两份代码保留在点读区，便于与你贴出的实现对照。

NumPy：将原来的 eps / clip / loss 三行替换为

# y 只能是 0 或 1；直接使用输出层线性值
loss = np.logaddexp(0.0, -z2) if y == 1 else np.logaddexp(0.0, z2)

# 梯度仍然是：
dL_dz2 = y_hat - y

np.logaddexp(a,b) 稳定地计算 log(exp(a)+exp(b))。y=1 时 BCE=log(1+exp(−z2))；y=0 时 BCE=log(1+exp(z2))，这个写法与解析梯度一致。

Torch：同样可以在 z2 上计算

# 这题的 y 是 0/1，先构造正负方向一致的线性值
signed_z = (1.0 - 2.0 * y) * z2
loss = torch.nn.functional.softplus(signed_z)

# 或使用专门的 BCE-with-logits 函数：
loss = torch.nn.functional.binary_cross_entropy_with_logits(z2, y)

这些函数接收的是 z2（logit），不是 y_hat。二者是替代写法，选择一种即可；手动梯度步骤保持不变。

clip 之后，原手动梯度是不是 clip 函数的导数？

不是。进入真正的截断区间后，clip 对原概率的局部导数为 0；而 y_hat−y 是未截断 Sigmoid+BCE 的导数。原版把 clip 作为 loss 的数值保护，仍保留原目标的解析梯度。直接计算稳定 BCE 能避免这处目标与导数的差异。

为什么单样本没有梯度除以 n？

这里 loss 是一个样本的 BCE。若题目改成 B 个样本的平均损失，梯度才要按所定义的平均方式除以 B。本题没有批量平均。

07 / 从看懂到手撕

先记四段，再记每段的形状

  1. Forward：x@W1+b1 → ReLU → dot(W2,h)+b2 → Sigmoid。
  2. Loss：BCE 在更新前算；极端输入推荐稳定 logit 形式。
  3. Backward：δ2=p−y；求 dW2、db2；乘旧 W2；乘 ReLU 掩码；用 outer 求 dW1，db1=δ1。
  4. Update & Return：所有梯度计算完，再统一“旧参数−lr×梯度”；返回旧 loss 与新参数。

复盘 1：哪个乘法方向对？

x=(2,)，W1=(2,3)。

查看答案
x@W1 得到 (3,)；W1.T@x 也可。W1@x 的维度不匹配。

复盘 2：p−y 后还要乘 p(1−p) 吗？

查看答案
不用。p−y 已经是 BCE 和 Sigmoid 合并后的 dL/dz2，再乘会重复。

复盘 3：outer 的输出是什么？

x=[1,2]，δ1=[a,b,c]。

查看答案
[[a,b,c],[2a,2b,2c]]，形状 2×3，与 W1 对应。

复盘 4：loss 是新参数算的吗？

查看答案
不是。返回本次更新前的 loss；若要看更新后的 loss，需额外再前向一次，这不是题目要求的返回值。

最快的一组口诀

输出误差 p−y；权重梯度乘输入；向前传回乘旧权重；ReLU 乘门；第一层外积；全部求完再更新。

这题复杂度怎么回答？

固定 2→3→1、只有一个样本：参数数目和运算数目都固定，因此时间和额外空间都可记为 O(1)。输入数值变大，不代表神经元数量变多。

如果推广为 D 维输入、H 个隐藏神经元、单输出，则前向、反向和更新的时间为 O(DH+H)；显式保存权重副本、权重梯度和新权重的实现，额外空间也是 O(DH+H)。这与固定小网络的 O(1) 并不矛盾。

面试口述：“我先按给定参数做前向，用 ReLU 得到三个隐藏激活，再用 Sigmoid 得到输出概率并计算 BCE。反向从 δ2=p−y 开始，输出权重梯度是 δ2×h，隐藏输出梯度是 δ2×旧 W2；乘 ReLU 掩码得到 δ1，再用 x 和 δ1 的外积得到 dW1。所有梯度算完后统一更新，返回更新前的 loss 和更新后的四组参数。”
