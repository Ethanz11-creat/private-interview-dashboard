01 · 做题前先记住要求

完整题干

P4489. Self-Attention 机制｜难度：5

给定序列长度 n、特征维度 d 的输入矩阵 X（大小为 n × d），以及三组权重矩阵 Wq, Wk, Wv（大小均为 d × d），请实现单头 Self-Attention 的前向计算，返回 Attention 输出矩阵 O。

  1. 线性映射：Q = X · Wq，K = X · Wk，V = X · Wv。
  2. 缩放点积得分：S = Q · Kᵀ / √d，其中 Kᵀ 是 K 的转置。
  3. 行级 Softmax：A = softmax(S)，每行独立计算。
  4. 输出：O = A · V。

返回 O，形状为 n × d。与标准答案的误差不超过 1e-4 即视为正确。

参数与返回值

参数含义形状
n序列长度，token / 位置数量整数
d每个位置的特征维度整数
X输入浮点矩阵n×d
Wq、Wk、Wv三组给定的线性映射权重均为 d×d
O（返回）Attention 输出矩阵n×d

约束

  • 1 ≤ n ≤ 50，1 ≤ d ≤ 50。
  • X[i][j]、Wq[i][j]、Wk[i][j]、Wv[i][j] 均为浮点数。
  • 上述每个元素均在 [-3, 3] 范围内。

示例 1

输入

n = 2, d = 2
X  = [[1,0],[0,1]]
Wq = [[1,0],[0,1]]
Wk = [[1,0],[0,1]]
Wv = [[1,2],[3,2]]

输出

O = [[1.6605,2.0000],
     [2.3395,2.0000]]

Q=K=X。先计算 Q·Kᵀ/√2，再逐行 Softmax，最后加权 V。

返回类型要区分：题干描述的是数值矩阵；你提供的两个代码版本用 f"{x:.4f}" 返回字符串矩阵。本页保留原写法供逐行学习，同时提供浮点返回版本。按平台给定的函数接口选择；不能把字符串和浮点数视为同一种类型。
02 · 先把运算串起来

每个位置，从所有位置中混合信息

输入的一行可以理解为一个 token 的特征。每个位置先生成三份表示：Q 用于发起匹配，K 用于被匹配，V 是被加权的信息。这些名称帮助记忆，但计算完全由题目给出的矩阵公式决定。

对于第 i 个位置，拿 Q[i] 分别与 K[0]、K[1]、… 做点积，得到 n 个分数。把这 n 个分数做 Softmax，得到 n 个权重，再用它们加权 n 个 Value，输出一个长度为 d 的向量。

S[i,j] = Σt=0…d−1 Q[i,t] × K[j,t] / √d
A[i,j] = exp(S[i,j] − max(S[i,:])) / Σr=0…n−1 exp(S[i,r] − max(S[i,:]))
O[i,t] = Σj=0…n−1 A[i,j] × V[j,t]

矩阵形状是手撕时的检查工具

步骤形状相乘结果
Q / K / V = X @ W(n,d) @ (d,d)(n,d)
K.T交换行列(d,n)
Q @ K.T(n,d) @ (d,n)(n,n)
行 Softmax每一行 n 项归一化(n,n)
A @ V(n,n) @ (n,d)(n,d)
行、列分别代表什么？ S/A 的第 i 行表示“第 i 个位置看所有位置”；第 j 列表示“被看的第 j 个位置”。A[i,j] 才是归一化后的权重，S[i,j] 是原始得分，可以为负，不能直接当概率。

@ 与 * 必须分清

@ 做矩阵乘法，包含相乘后求和；* 对数组对应元素相乘，不完成点积。本题三次投影、得分和输出均使用 @。

为什么除以 √d？

点积累加 d 项，维度增大时得分的尺度容易变大。在各分量近似独立、均值为 0、方差为 1 的简化假设下，点积方差约为 d，除以 √d 后方差约为 1，缓解 Softmax 过度集中。这是尺度控制，不保证每个数据集的实际方差恰好为 1。

本题没有额外要求：按给定公式做单头计算，所有位置都可被关注，包括自己；没有因果遮罩、残差、输出投影或训练更新步骤。

03 · 点一行，看一行

NumPy 与 PyTorch 逐行拆解

先熟悉 NumPy 的展开版，再看 PyTorch 如何用一行封装 Softmax。空行仅作分段，显示的行号对应下方完整代码。

NumPy · Python
完整 NumPy 代码（与你给的版本一致，省略说明性注释）
import math
import numpy as np
from typing import List

class Solution:
    def selfAttention(
        self,
        n: int,
        d: int,
        X: List[List[float]],
        Wq: List[List[float]],
        Wk: List[List[float]],
        Wv: List[List[float]]
    ) -> List[List[str]]:
        X = np.array(X, dtype=float)
        Wq = np.array(Wq, dtype=float)
        Wk = np.array(Wk, dtype=float)
        Wv = np.array(Wv, dtype=float)

        Q = X @ Wq
        K = X @ Wk
        V = X @ Wv

        S = (Q @ K.T) / math.sqrt(d)
        S = S - np.max(S, axis=1, keepdims=True)
        exp_S = np.exp(S)
        A = exp_S / np.sum(exp_S, axis=1, keepdims=True)

        O = A @ V
        res = [[f"{x:.4f}" for x in row] for row in O]
        return res
完整 PyTorch 代码
import math
import torch
from typing import List

class Solution:
    def selfAttention(
        self,
        n: int,
        d: int,
        X: List[List[float]],
        Wq: List[List[float]],
        Wk: List[List[float]],
        Wv: List[List[float]]
    ) -> List[List[str]]:
        X = torch.tensor(X, dtype=torch.float64)
        Wq = torch.tensor(Wq, dtype=torch.float64)
        Wk = torch.tensor(Wk, dtype=torch.float64)
        Wv = torch.tensor(Wv, dtype=torch.float64)

        Q = X @ Wq
        K = X @ Wk
        V = X @ Wv
        S = (Q @ K.T) / math.sqrt(d)
        A = torch.softmax(S, dim=1)
        O = A @ V
        return [[f"{x:.4f}" for x in row] for row in O.tolist()]

04 · 跟着真实矩阵算

从输入走到输出

选择数据，再逐步展开。示例中的单位阵方便验证；也可以切换到 n≠d 的场景，避免“所有矩阵都是 2×2”的错觉。

选中一行：它怎样混合所有 Value？

条形统一使用 0～1 的概率刻度。矩阵显示保留六位，计算使用未舍入数值；极小量显示科学计数法。这个演示只处理展示用的小矩阵，题目支持 n、d 最大为 50。

原题计算的关键结果
Q = K = [[1,0],[0,1]]
V = [[1,2],[3,2]]

原始 S ≈ [[0.70710678,0],
          [0,0.70710678]]
A ≈ [[0.66976155,0.33023845],
     [0.33023845,0.66976155]]

O[0,0] = 0.66976155×1 + 0.33023845×3 ≈ 1.66047690
O[0,1] = 0.66976155×2 + 0.33023845×2 = 2
O[1,0] ≈ 2.33952310

第二列全为 2，因为所有 Value 的第二个分量均为 2，而每行权重和为 1。输出行不是“直接复制最近的一个 Value”，它是多个 Value 的加权和。

05 · 最容易写错的三件事

转置、axis=1、keepdims=True

1. K.T：让 Query 能匹配每个 Key

Q[i] 与 K[j] 都是长度 d 的行向量。矩阵乘法要拿左矩阵一行乘右矩阵一列，所以把 K 的第 j 行转成 K.T 的第 j 列。于是结果第 (i,j) 项就是这两个向量的点积。

写成 Q @ K，一般维度不匹配；当 n=d 时可能刚好能运行，但仍然不是题目要求的两两行向量匹配。原题的 K 又恰好是单位阵，无法暴露这个错误，所以要用非对称样例检查。

2. axis=1：沿列归约，给每行一个结果

操作得到的内容形状
np.max(S,axis=1)每行最大值(n,)
np.max(S,axis=1,keepdims=True)每行最大值，保留列维(n,1)
np.sum(exp_S,axis=1,keepdims=True)每行指数和(n,1)
torch.softmax(S,dim=1)每行 Softmax 后的完整权重(n,n)

NumPy 的 axis=1 和 PyTorch 的 dim=1 都选第 1 维。对于二维矩阵，第 0 维是行，第 1 维是列；沿列操作，等于对每行中的各列做计算。

3. keepdims=True：保留成一列，再按行广播

看一个演示矩阵 S=[[1,2,3],[4,5,6],[7,8,9]]。下面两种减法都能运行，但意义不同：

正确：最大值是 3×1

np.max(S, axis=1, keepdims=True)
# [[3],
#  [6],
#  [9]]

S - 上面的列向量
# [[-2,-1,0],
#  [-2,-1,0],
#  [-2,-1,0]]

3、6、9 分别扩展到各自所在行。

丢维度：最大值是长度 3 的向量

np.max(S, axis=1)
# [3,6,9]，形状 (3,)

S - [3,6,9]
# [[-2,-4,-6],
#  [ 1,-1,-3],
#  [ 4, 2, 0]]

广播从尾部维度对齐，变成每行都减 [3,6,9]，按列减了不同数。

本题 S 总是方阵 (n,n)，删掉 keepdims 很可能不报错，却给出错误结果。原题两行最大值相同，错误广播又会碰巧表现正常。分母求和时也要保留为 (n,1)。

减行最大值为何不改变概率？

令 mi = max(S[i,:])：
exp(S[i,j]−mi) / Σr exp(S[i,r]−mi)
= [exp(S[i,j]) · exp(−mi)] / [exp(−mi) · Σr exp(S[i,r])]
= exp(S[i,j]) / Σr exp(S[i,r])

每行的最大值可以不同，同一行共同平移的因子能约掉。平移后最大得分为 0，因此每行至少有一个指数等于 1，分母至少为 1；浮点下极小指数可以下溢成 0，但这一行不会全部变成 0。

稳定 Softmax 保护指数运算。若前面的矩阵乘法已经产生 inf 或 NaN，它不能修复那些值；本题有限输入范围配合双精度，不会出现那种中间乘法溢出。

06 · 看懂 @ 内部在做什么

普通 Python 循环对照

下面版本不用 NumPy 或 PyTorch，返回浮点矩阵。它更适合理解矩阵乘法的三个循环；提交运行速度与平台环境有关，已有 NumPy 环境时可以使用上面的版本。

import math

class Solution:
    def selfAttention(self, n, d, X, Wq, Wk, Wv):
        # A 的列数必须等于 B 的行数
        def matmul(A, B):
            rows, middle, cols = len(A), len(B), len(B[0])
            C = [[0.0] * cols for _ in range(rows)]
            for i in range(rows):
                for j in range(cols):
                    for t in range(middle):
                        C[i][j] += A[i][t] * B[t][j]
            return C

        Q = matmul(X, Wq)
        K = matmul(X, Wk)
        V = matmul(X, Wv)
        KT = [[K[j][t] for j in range(n)] for t in range(d)]
        S = matmul(Q, KT)
        scale = math.sqrt(d)
        A = []
        for row in S:
            scaled = [score / scale for score in row]
            max_score = max(scaled)
            exp_row = [math.exp(score - max_score) for score in scaled]
            total = sum(exp_row)
            A.append([value / total for value in exp_row])
        O = matmul(A, V)
        return O  # 浮点二维列表

三个循环的对应关系

循环变量含义在 Q @ K.T 中
i结果的行当前 Query 的位置
j结果的列被匹配 Key 的位置
t相乘后累加的中间维特征下标，0…d−1

C[i][j] += A[i][t] * B[t][j] 就是矩阵乘法的定义。这里 matmul 的参数 A、B 只是通用变量名，不一定是注意力权重 A。

用 [[0.0] * cols for _ in range(rows)] 逐行新建列表；不要写成 [[0.0] * cols] * rows，后者会让多行引用同一个列表，修改一行影响其他行。

为什么循环版也要减最大值？

实现工具不同，公式要求相同。每行仍然先除 √d，再取该行最大值，求指数并除该行指数和。无需平方根距离、排序或选取 top-K。

07 · 根据元素数量数复杂度

时间 O(nd² + n²d)，额外空间 O(nd + d² + n²)

步骤工作量依据
三次 X @ WO(nd²)每次有 nd 个输出，每项累加 d 次；三次是常数倍
Q @ K.TO(n²d)n² 个得分，每个累加 d 次
行 SoftmaxO(n²)最大值、指数、求和与除法都遍历 n² 项
A @ VO(n²d)nd 个输出，每项累加 n 次
格式化结果O(nd)遍历输出元素；按固定浮点精度分析

按常规稠密矩阵乘法分析，总时间为 O(nd²+n²d)。不能只记 O(n²)：投影与输出的计算也要计入。令 n=d=m 时，整体时间为 O(m³)。

保存的对象大小
复制后的 X，以及 Q、K、V、O常数个 n×d → O(nd)
复制后的 Wq、Wk、Wv常数个 d×d → O(d²)
S、exp_S、A 与计算临时量常数个 n×n → O(n²)
每行最大值或指数和n×1 → O(n)

你给的 NumPy / PyTorch 实现会复制权重和输入，所以额外空间写 O(nd+d²+n²)；不把返回输出计入也不改变这个阶。普通循环版本直接读取输入权重，主要额外空间是 O(nd+n²)。

联系你之前问的 O(1)：变量名的个数固定，不代表空间固定。n、d 两个整数是常数个标量；但 A 一个变量指向 n² 个元素，n 翻倍时元素数量变为 4 倍。math.sqrt(d) 是一个标量，np.exp(S) 是 n×n 矩阵。

复杂度按 n、d 随输入变化来分析，即使本题将它们限制为 50，也通常不写“所有步骤 O(1)”。这里采用标准浮点运算与常规矩阵乘法成本模型。

n=3，d=2，S 是什么形状？

查看答案
(3,3)。得分是在 3 个位置之间两两匹配，列数是位置数 n，而不是特征维度 d。

n=1，输出一定等于 X 吗？

查看答案
A=[[1]]，所以 O=V=X@Wv；只有 V 恰好等于 X 时，输出才等于 X。

A 是概率，O 也一定在 0～1 吗？

查看答案
A 每项在 0～1，每行和≈1。O 是 Value 的加权和，可以负数，也可以大于 1。每个输出分量位于所有对应 Value 分量的最小值与最大值之间（允许浮点误差）。

Q=K，A 一定对称吗？

查看答案
原始 S=Q@Q.T/√d 对称。但每行 Softmax 的分母可能不同，A 一般不对称。原题恰好每行分母相同，属于特殊情况。

常见错误

容易写错正确记法
X * Wq矩阵乘法 X @ Wq
Q @ KQuery 行对 Key 行：Q @ K.T
除 d 或 √n除 √d，本题 Key 维度为 d
axis=0 / dim=0每行归一化：axis=1 / dim=1
删掉 keepdims=True行分母与行最大值保持 (n,1)
A * V 或 V @ A输出 O=A @ V
将 S 的所有元素一起归一化每行是一个独立的分布，行和≈1；整矩阵和≈n
以为“Self”表示只能看自己Q、K、V 来自同一个 X，每个位置可以看全部位置
面试口述：“我先把 X 通过三组权重映射成 Q、K、V。用 Q 乘 K 的转置得到所有位置两两之间的得分，除以根号 d。对得分逐行做稳定 Softmax，每行先减最大值再求指数，除以本行指数和。最后 A 乘 V 得到 n×d 的输出。常规矩阵乘法下，时间是 O(nd²+n²d)，这份数组实现的额外空间是 O(nd+d²+n²)。”

建议练习：第一次对照形状写；第二次只看四段标题；第三次只看题干，自己补全整个方法。检查原题、n≠d 的非对称样例与 n=1，避免只靠原题判断正确。
