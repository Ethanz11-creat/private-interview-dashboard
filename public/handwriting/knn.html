01 / 完整题干 · 手撕前先看

P4499. K 最近邻算法（KNN）

难度：5。以下题干根据你提供的题面整理，输入、返回值、示例和数据范围完整保留。

题目描述

给定一个测试样本 x_test，以及训练数据矩阵 X 和训练标签列表 y。请实现 KNN 分类：计算测试样本到每个训练样本的欧氏距离，选择最近的 K 个训练样本，根据它们的标签进行多数投票，返回最终预测标签。

X 有 N 个训练样本，每个样本有 d 个特征，即形状为 N × d；y[i] 是 X[i] 的类别标签，取值为 0 或 1；x_test 是长度为 d 的特征向量。

算法要求

  1. 计算距离：对每个训练样本 X[i]，计算它与 x_test 的欧氏距离：dᵢ = √(Σⱼ (x_test[j] − X[i][j])²)。
  2. 寻找最近邻：按距离从小到大选出 K 个训练样本的下标。
  3. 多数投票：读取这 K 个样本的标签，返回出现次数最多的标签。

输入参数

参数含义
X形状为 N×d 的训练数据矩阵；X[i] 是第 i 个训练样本。
y长度为 N 的标签列表；y[i] 对应 X[i]，取值为 0 或 1。
x_test长度为 d 的测试样本特征向量。
K参与投票的最近邻数量。

返回值

y_pred：最终预测标签，返回整数 0 或 1。

示例

输入：
K = 2
X = [[1, 2], [2, 1], [3, 3]]
y = [0, 1, 1]
x_test = [2, 2]

输出：
y_pred = 1

数据范围与提示

  • −1000 ≤ X[i][j], x_test[j] ≤ 1000。
  • 每个训练标签 y[i] ∈ {0, 1}。
  • 1 ≤ K ≤ N。
  • 欧氏距离总是非负，即 dᵢ ≥ 0。
题面与实现约定要区分：示例中最近的两个标签是 [0,1]，票数相同，但输出为 1。题面没有单独写出通用平票规则，本页根据示例采用“平票返回 1”。距离相同的样本则用稳定排序保持输入顺序；这是本页的确定性实现约定，题面未明确规定这种平局的取舍。

手撕提交的方法：knn_classification(self, X, y, x_test, K)。题目只要求预测一个测试样本，不需要训练中心或迭代更新。

04 / norm 究竟怎么算

每一行：坐标差平方 → 求和 → 开平方

距离 = √((第 1 个特征差)² + … + (第 d 个特征差)²)

你提供的说明里，公式只写了平方和，少了开平方；平方和叫“距离平方”。np.linalg.norm(..., axis=1) 默认计算这里的欧氏距离，包含开平方。

X_arr = np.array(X, dtype=float)              # (N,d)
test_arr = np.array(x_test, dtype=float)      # (d,)
distances = np.linalg.norm(X_arr - test_arr, axis=1)

为什么不需要写 None？

X_arr 是 (N,d)，test_arr 是 (d,)。从右侧对齐时，后者可按 (1,d) 广播，所以每一行都减去同一个测试样本。

这次只有一个测试样本，与 K-Means 里“n 个点与 k 个中心两两配对”不同，不需要手工增加中间维度。

为什么用 axis=1？

相减后的数组形状为 (N,d)。第 0 维对应样本，第 1 维对应特征。

axis=1 把每行的 d 个特征差合成一个距离，输出 (N,)。axis=0 会沿不同样本计算，得不到所需的每个样本距离。

等价写法：np.sqrt(np.sum((X_arr - test_arr) ** 2, axis=1))。只为了比较远近时，也可以省掉 sqrt，直接按距离平方排序；平方根对非负数保持大小顺序。

argsort 和 sort 的差别

输入 / 操作结果用途
a = [3.2, 0.5, 1.7]原顺序：第 0、1、2 个三个训练样本的距离。

06 / 原代码最容易背错的一句

max(set(nearest_labels), key=nearest_labels.count)

nearest_labels = [y[i] for i in nearest_indices]
y_pred = max(set(nearest_labels), key=nearest_labels.count)

这句先去重，再比较每种标签出现的次数，最后返回标签本身。它返回的不是票数。

拆开看例如 nearest_labels = [1,0,1]具体含义
set(nearest_labels){0,1}只保留有哪些不同标签；集合不保证遍历顺序。
nearest_labels.count(0)1标签 0 出现 1 次。
nearest_labels.count(1)2标签 1 出现 2 次。
key=nearest_labels.count把 count 方法交给 maxmax 会对候选标签调用 count，比较票数。
max(...)返回 1，不是 2返回比较分数最大的候选标签。

为什么 count 后面没有括号？

key=nearest_labels.count

# 可以理解为：
score_0 = nearest_labels.count(0)
score_1 = nearest_labels.count(1)
# max 比较 score，但返回 0 或 1

key 需要一个“可调用对象”。把方法交进去，让 max 为各个候选值调用它。这里不写 count()，因为此时没有传入要统计的标签。

平票时，原版为什么不能保证 1？

nearest_labels = [0, 1]
# count(0) == count(1) == 1

# 明确统计 + 明确处理平票
count_0 = nearest_labels.count(0)
count_1 = nearest_labels.count(1)
y_pred = 1 if count_1 >= count_0 else 0

max 遇到相同的 key 值，会保留首先遇到的候选标签；集合不承诺你需要的顺序。本次验证中原版返回了 0，与示例的 1 不符。用 >= 明确表达平票也返回 1。

能不能保留一行 max 写法，并处理平票？
y_pred = max(
    set(nearest_labels),
    key=lambda label: (nearest_labels.count(label), label)
)

比较二元组时先比较票数，票数相同再比较标签值，因此平票时 1 胜过 0。对于这道只包含 0、1 的题，直接统计两种票数更容易手撕。

两种“相同”需要分开处理

距离相同：影响哪 K 个样本被选中。本页用 kind="stable" 保持原输入顺序，在 K 的边界也按这个顺序选择。

票数相同：影响预测标签。本页根据给定示例约定返回 1。

题面没有完整说明两类平局的规则；这里明确写出实现约定，便于复现。如果平台另有规则，应按其规则修改。

KNN 和 K-Means 为什么名字很像，代码却不同？

KNN 是分类：训练样本已有标签，给新样本找 K 个邻居投票，K 表示邻居数。这里没有中心更新和迭代训练。

K-Means 是聚类：样本没有已知标签，反复分组、求均值更新中心，K 表示簇数。

07 / 还原成普通 Python

不依赖 NumPy 时，底层操作就是这些

这是完整的理解用版本：距离平方排序、按原下标查标签、计数投票。距离相同时按下标排序；平票返回 1，与上面的约定一致。

def knn_classification(X, y, x_test, K):
    N = len(X)
    d = len(x_test)
    distances_sq = []

    for i in range(N):
        total = 0
        for j in range(d):
            diff = X[i][j] - x_test[j]
            total += diff * diff
        distances_sq.append(total)

    # 排序的是下标，而不是 X 或 y
    indices = sorted(
        range(N), key=lambda i: (distances_sq[i], i)
    )
    nearest_indices = indices[:K]
    nearest_labels = [y[i] for i in nearest_indices]

    count_0 = nearest_labels.count(0)
    count_1 = nearest_labels.count(1)
    return 1 if count_1 >= count_0 else 0

普通循环中的 j 遍历特征，对应 NumPy 的 axis=1。range(N) 产生所有样本下标，key 指定每个下标按什么排序。

列表推导式的普通写法

# 简写
nearest_labels = [y[i] for i in nearest_indices]

# 展开
nearest_labels = []
for i in nearest_indices:
    nearest_labels.append(y[i])

条件表达式的普通写法

# 简写
y_pred = 1 if count_1 >= count_0 else 0

# 展开
if count_1 >= count_0:
    y_pred = 1
else:
    y_pred = 0
08 / 从理解到盲写

记数据路径，再记函数名

  1. 转换输入：X 是二维浮点数组，x_test 是一维浮点数组。
  2. 计算距离：广播相减，norm 沿 axis=1，得到 N 个距离。
  3. 选择邻居：argsort 返回排序下标，[:K] 取前 K 个。
  4. 查询标签：[y[i] for i in nearest_indices]。
  5. 计票返回：分别 count(0)、count(1)，显式处理平票。

复盘 1：这个输出形状是什么？

X.shape = (5,3)，x_test.shape = (3,)，相减再 norm(axis=1)。

查看答案
差值数组是 (5,3)；距离数组是 (5,)，每个训练样本对应一个距离。

复盘 2：argsort 返回哪三个数？

distances = [8,2,5]，K = 2。

查看答案
argsort 得到 [1,2,0]；截取后 nearest_indices 是 [1,2]。返回的是下标，不是 [2,5]。

复盘 3：为什么还要查一次 y？

nearest_indices = [2,0]，y = [0,1,1]。

查看答案
下标不是标签。取 [y[2],y[0]]，得到 [1,0]。

复盘 4：> 和 >= 会差在哪？

count_0 = 1，count_1 = 1。

查看答案
条件 count_1 > count_0 为 False，会返回 0；条件 count_1 >= count_0 为 True，返回 1，符合本题示例。

这版的复杂度怎么说？

步骤时间原因
转换输入与计算距离O(Nd)N 个训练样本，每个比较 d 个特征。
对所有距离 argsortO(N log N)对 N 个距离完整排序，不只是对 K 项排序。
查 K 个标签并计票O(K)只包含两类，两个 count 各扫描 K 项。
总时间O(Nd + N log N)K≤N；不需要迭代次数这一项。

NumPy 版本额外空间是 O(Nd + N)，通常简记 O(Nd)。输入列表转成数组，以及广播相减结果，都可能有 N×d 个元素；距离和排序下标有 N 项，邻居列表有 K 项。d≥1、K≤N，所以整体由 Nd 主导。

如果只分析“已经有训练数组之后”的纯 Python 逐点版本，额外空间可以是 O(N)。这不等于上面的 NumPy 写法也是 O(N)：相减会产生整个 (N,d) 数组。

面试口述：“我先计算测试样本到每个训练样本的欧氏距离，按距离排序得到原下标，取前 K 个，再用这些下标取标签，统计 0 和 1 的票数。根据给定示例，票数相同时返回 1。距离计算是 O(Nd)，完整排序是 O(N log N)。”
