01 / 完整题干 · 手撕前先看

K-Means 聚类算法

难度：5。以下题干根据你提供的题面整理，输入、返回值、初始中心、示例和数据范围完整保留。

题目描述

实现一个二维数据的 K-Means 聚类算法。给定 n 个二维数据点 nums，将它们划分为 k 个簇，并返回最终的聚类中心和每个数据点所属的聚类标签。

其中 nums[i] = [xᵢ, yᵢ] 表示第 i 个二维数据点。聚类最多进行 max_iter 次迭代；如果在此之前收敛，可以提前停止。

初始聚类中心：必须从输入的数据点中，选择读入顺序的前 k 个点作为初始中心，即 nums[:k]，不是随机选择。

输入参数

参数含义
n数据点数量。
k聚类数，即最终中心的数量。
max_iter最大迭代次数；提前收敛时可停止。
numsn 行、2 列的二维坐标列表，每行是一个 [x,y] 点。

返回值

  1. 长度为 k 的二维中心列表：[[x₁,y₁], [x₂,y₂], …, [xₖ,yₖ]]，每个元素是一个最终聚类中心。
  2. 长度为 n 的整数标签列表：每个标签范围是 [0,k−1]，顺序必须与 nums 中的数据点顺序一致。

精度要求：中心坐标保留 4 位小数，误差容忍度为 1e−3。

示例

输入：
n = 4
k = 2
max_iter = 100
nums = [[1.0, 1.0], [1.5, 2.0], [5.0, 8.0], [8.0, 8.0]]

输出：
[[1.2500, 1.5000], [6.5000, 8.0000]]
[0, 0, 1, 1]

数据范围

  • 1 ≤ n ≤ 2 × 10⁴。
  • 1 ≤ k ≤ 20，并且 k ≤ n。
  • 1 ≤ max_iter ≤ 100。
  • −10⁴ ≤ nums[i][0], nums[i][1] ≤ 10⁴。

本页代码如何完成聚类？

  1. 复制前 k 个点作为中心。
  2. 每轮将每个点分配给最近的中心。
  3. 若新旧标签完全相同，则提前停止。
  4. 否则按当前分组，对每个簇的 x、y 分别求均值，更新中心；重复直到停止或达到迭代上限。

手撕提交的方法：kMeans(self, n, k, max_iter, nums)。本页实现用“标签不变”判定收敛；遇到空簇时保留该簇的旧中心，相同距离时 argmin 选择下标最小的中心。这些实现细节在后文逐行解释。

02 / 先把变量对上号

整个程序只在反复更新两样东西

labels 记录每个点属于哪个簇；centers 记录每个簇的中心在哪。points 是原始数据，整个过程保持不变。

变量形状 / 类型示例与含义
n, k, max_iter三个整数4, 2, 100：4 个点，2 个簇，最多循环 100 轮。
points(n, 2)，浮点数组每行一个点，每行两列分别是 x、y。
centers(k, 2)，浮点数组每行一个中心；第 j 行就是簇 j 的中心。
labels(n,)，整数数组[0, 0, 1, 1]：前两个点属于簇 0，后两个属于簇 1。
dists(n, k)，浮点数组dists[i, j] 是第 i 个点到第 j 个中心的距离平方。
cluster_points(m, 2)，浮点数组筛选出当前簇中的 m 个点；m 可以是 0。
1. 初始化

前 k 个点当中心；旧标签全部设成 -1。

2. 给点分组

计算距离，每个点选择最近中心的下标。

3. 判断停止

新旧标签相同，分组稳定，退出循环。

4. 更新中心

按新标签筛点，分别对 x、y 求平均。

形状 (n, 2) 的意思：这是一个 n 行、2 列的数组。(n,) 则是一维数组，有 n 个元素；括号里的逗号是 Python 单元素元组的写法。

04 / 最值得单独理解的一行

距离公式：先两两相减，再平方，再加起来

dists = np.sum((points[:, None, :] - centers[None, :, :]) ** 2, axis=2)

目标是得到一张“距离表”：每行对应一个点，每列对应一个中心。下面展示第一轮实际使用的数组。

: 和 None 怎么读？

: 表示这一维全部保留；None 表示在这里增加一个长度为 1 的维度。

points[:, None, :]：保留所有点，在中间加一维，保留 x、y 两列。

centers[None, :, :]：在最前面加一维，保留所有中心和两列坐标。

为什么可以直接相减？

NumPy 从末尾对齐维度：(n, 1, 2) 与 (1, k, 2) 相减时，长度为 1 的维度可扩展到另一方的长度，结果是 (n, k, 2)。

这是“广播”。增加维度和广播不要求你手工复制 n×k 份原数据；但相减、平方和求和的结果需要实际存储。

读 axis 的方法：(n, k, 2) 的第 0 维是点，第 1 维是中心，第 2 维是 x、y 坐标差。因此 axis=2 是把每一对点与中心的两个坐标差平方相加。

簇 0 · 蓝色簇 1 · 橙色尚未分组 · 灰色
停止条件为什么放在更新中心之前？上一轮已经根据旧标签求过均值。如果这一轮标签完全相同，再求均值仍会得到相同中心，所以可以直接停止。初始标签全是 -1，确保第一轮不会误判成“已经收敛”。

这里使用代码中的“标签不变”作为停止条件，没有额外添加中心位移阈值。达到 max_iter 时，返回最后一轮的分组及该分组更新出的中心；这不保证已经收敛。

06 / 把 NumPy 语法翻译成熟悉的循环

短代码背后，仍然是这些操作

下面是理解用的等价操作。手撕时可以先在脑中还原这些循环，再写 NumPy 版本。

计算所有距离平方

# NumPy
dists = np.sum(
    (points[:, None, :] - centers[None, :, :]) ** 2,
    axis=2
)

# 普通循环：i 是点，j 是中心
dists = []
for i in range(n):
    row = []
    for j in range(k):
        dx = points[i][0] - centers[j][0]
        dy = points[i][1] - centers[j][1]
        row.append(dx * dx + dy * dy)
    dists.append(row)

给每个点选择最近中心

# NumPy
new_labels = np.argmin(dists, axis=1)

# 普通循环：返回下标，不是距离值
new_labels = []
for i in range(n):
    best_j = 0
    for j in range(1, k):
        if dists[i][j] < dists[i][best_j]:
            best_j = j
    new_labels.append(best_j)

# 严格用 <：同样远时保留先出现的中心
# 对应 np.argmin 的首次最小值规则

根据标签筛选点

# NumPy
cluster_points = points[labels == j]

# 普通循环
cluster_points = []
for i in range(n):
    if labels[i] == j:
        cluster_points.append(points[i])

labels == j 对每一个标签做比较，生成布尔数组。points[布尔数组] 只保留 True 对应的行，称为“布尔索引”。

分别求 x、y 平均值

# NumPy
centers[j] = np.mean(cluster_points, axis=0)

# 普通循环（前提：簇中有点）
sum_x = 0
sum_y = 0
for x, y in cluster_points:
    sum_x += x
    sum_y += y
m = len(cluster_points)
centers[j] = [sum_x / m, sum_y / m]

axis=0 沿着“点”这一维求均值，合并各行，留下两列结果；不是把 x、y 混在一起平均。

三个 axis，分别在处理哪一维？

操作输入形状沿哪一维操作输出形状
sum(..., axis=2)(n, k, 2)把 x、y 的差平方相加(n, k)
argmin(..., axis=1)(n, k)在 k 个中心中选最小值的位置(n,)
mean(..., axis=0)(m, 2)对 m 个点的各列分别求平均(2,)
为什么距离没有开平方？

欧氏距离是 √((x₁−x₂)²+(y₁−y₂)²)。所有距离平方都非负，平方根保持大小顺序，所以最小距离平方对应的中心，也就是最近中心。不做开平方，可以省掉一项计算。

为什么 centers 要 copy()，labels 却可以直接赋值？

points[:k] 通常是原数组的切片视图。直接拿它当 centers，后续 centers[j] = ... 可能改到原始点。.copy() 创建独立数组，隔离这类修改。

labels = new_labels 是把变量绑定到本轮新数组。随后代码只读取标签，并没有修改这个数组的某个元素，因此这里不需要额外复制。

空簇、相同距离分别怎么办？

空簇：len(cluster_points) == 0 时跳过更新，保持该簇的旧中心，避免对空数组求均值得到 NaN。

相同距离：np.argmin 返回第一个最小值的位置，因此选择下标较小的中心。重复初始中心时，这个规则可能导致第一轮出现空簇。

为什么最后 round() 和 tolist()？

计算过程保留完整精度，结束后才四舍五入到四位小数。float(x) 将 NumPy 标量转成普通 Python 浮点数；labels.tolist() 将 NumPy 数组转成 Python 列表。

round(1.25, 4) 的显示仍可能是 1.25；若打印文本必须有四位小数，用 f"{x:.4f}"。这个函数返回数值列表，不需要把中心转成字符串。

07 / 从看懂到自己写出来

按六个动作盲写，比逐字背整段更容易

  1. 初始化：points 转浮点数组；前 k 个点复制成 centers；labels 全设为 -1。
  2. 迭代：最多 max_iter 轮。
  3. 算距离并分组：广播相减、平方、沿 axis=2 求和；沿 axis=1 找 argmin。
  4. 判停止并更新标签：array_equal 相同则 break；不同则 labels = new_labels。
  5. 更新中心：遍历簇 j，布尔筛点；非空就沿 axis=0 求 mean。
  6. 返回：中心最后 round，标签 tolist。

查看答案
(n, 1, 2) 和 (1, k, 2)；相减得到 (n, k, 2)。

查看答案

查看答案

复盘 4：为什么初始标签是 -1？

能不能初始化成全 0？

查看答案
全 0 可能和第一轮分组相同，导致中心还没更新就提前停止。比如 k=1、点为 [[0,0],[2,0]]，正确中心应是 [1,0]。-1 不是有效标签，确保第一轮会执行更新。

复杂度也要能口述

设实际执行了 T 轮。每一轮有 n 个点，每个点比较 k 个中心，二维坐标只带来常数开销，所以时间复杂度是 O(T × n × k)。逐簇筛选和求均值也在这个量级内。

最大的临时数组是 (n, k, 2) 的坐标差和 (n, k) 的距离表，所以额外空间是 O(n × k)。即使本次输入已经固定，复杂度仍然描述 n、k 变化时空间如何增长；单个变量 n 或 k 本身按通常模型算 O(1)。

面试口述：“我先取前 k 个点作为中心。每轮计算所有点到各中心的距离平方，把每个点分给最近的中心。如果分组和上一轮一致就停止，否则按簇分别求坐标均值更新中心。空簇保留原中心，最多迭代 max_iter 次，最后返回中心与标签。”
