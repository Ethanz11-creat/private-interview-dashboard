P4498. 交叉注意力

01 / 原题整理

题干、完整输入与输出

难度：5。给定 Query 序列 \(X_Q\in\mathbb{R}^{T_Q\times d_{\mathrm{model}}}\)、Key / Value 序列 \(X_K\in\mathbb{R}^{T_K\times d_{\mathrm{model}}}\)，以及线性投影权重与偏置，实现交叉注意力的完整计算，返回二维浮点列表 \(O\)。

两条序列的长度可以不同。本题的输入特征维度相同，所有投影矩阵为方阵；没有 head 数参数，也不用 reshape 分头，所以是单头、无 mask的交叉注意力，d_k = d_model。

输入参数与返回值的形状
参数形状意义 / 原题样例
X_Q(T_Q, d_model)查询序列；(2,4)
X_K(T_K, d_model)提供 K 和 V 的序列；(2,4)
W_Q、W_K、W_V(d_model, d_model)三套不同的投影；(4,4)
b_Q、b_K、b_V(d_model,)每个 token 共用同一偏置；(4,)
W_O；b_O(d_model, d_model)；(d_model,)输出投影；(4,4)；(4,)
O（返回）(T_Q, d_model)每个 Query 一个输出；(2,4)

题目输出（两位小数）

题目提示与数值范围

  • 输入：−1000 ≤ X_Q[i,j]、X_K[i,j] ≤ 1000。
  • 权重：−10 ≤ W_Q、W_K、W_V、W_O 的元素 ≤ 10。
  • 偏置：−5 ≤ b_Q、b_K、b_V、b_O 的元素 ≤ 5。
  • 权重满足 0 ≤ A[i,j] ≤ 1，每行之和为 1；最终 O 可为任意实数矩阵。

资料未提供序列长度、特征维度上限或判题误差。本题不包含 batch、残差、层归一化、dropout 或因果 mask。

02 / 先理解来源

Query 提问，Key 匹配，Value 提供内容

查询侧 · X_Q

每行是一个需要读取信息的位置。只投影为 Q，决定“我想找什么”。

X_Q (T_Q,M)→Q = X_Q @ W_Q + b_Q

Q 的行数是 T_Q；最终也要给这 T_Q 个位置各返回一个向量。

信息侧 · X_K

每行是一个可供读取的位置。分别投影为 K 与 V：K 决定“怎么被匹配”，V 决定“被读取的内容”。

X_K (T_K,M)↗K = X_K @ W_K + b_K↘V = X_K @ W_V + b_V

K 和 V 的行数都是 T_K，第 j 个 Key 对应第 j 个 Value；它们用不同权重，所以数值不必相同。

两条路径在注意力矩阵中汇合

Q (T_Q,M)×Kᵀ (M,T_K)→S / A (T_Q,T_K)×V (T_K,M)→H / O (T_Q,M)

每行对应一个 Query，每列对应一个 Key。一行权重横向分配到全部 T_K 个位置，再按相同位置的 V 加权取回内容。

区别维度Self-AttentionCross-Attention
Q 的来源XX_Q
K / V 的来源同一份 X另一份 X_K
得分矩阵(T,T)(T_Q,T_K)，可为矩形
输出位置输入序列的 T 个位置查询序列的 T_Q 个位置

例如原始 Transformer 的 Encoder–Decoder Attention：Decoder 当前的隐藏状态提供 Q，Encoder 输出提供 K/V。Decoder 的每个位置通过注意力读取源句子的信息。这道题只是这一计算子模块，不包含整个 Encoder 或 Decoder。

来源和头数是两个独立概念。Self / Cross 描述 Q 与 K/V 是否来自同一序列；MHA / GQA / MQA 描述有多少 Query、K/V heads，以及怎样共享。交叉注意力也可以是多头；本题没有分头步骤。
03 / 公式对应代码

五步完整计算

1. 三次线性投影，先确认来源

Q = XQWQ + bQ
K = XKWK + bK
V = XKWV + bV

Q 为 (T_Q,M)，K/V 为 (T_K,M)。@ 将输入每行和权重每列作点积，偏置沿 token 行广播。V 用 X_K，不用 X_Q，也不是 K @ W_V。本例 Q 的首行是 X_Q 的第 0、2 个输入特征选中的权重行之和：[2,0,1,1]。

2. 缩放点积：每个 Query 与全部 Key 比较

S = QKT\sqrt{d_k}
Sij = \sum_{r=0}^{d_k-1} QirKjr\sqrt{d_k}

(T_Q,M) @ (M,T_K) 得到 (T_Q,T_K)。本题 d_k = K.shape[1] = 4，缩放因子 √4=2。每个元素 S[i,j] 是 Query i 与 Key j 的匹配分数。

在各维近似独立、均值为 0、方差为 1 的常见分析下，d_k 项点积的方差约为 d_k，除 √d_k 可将尺度控制到较稳定的范围，减轻 Softmax 过度尖锐、梯度过小的问题。这是尺度控制，并不保证所有输入都不会饱和；数值稳定还需要下一步减最大值。

3. 沿 Key 轴逐行 Softmax

mi = \max_{j} Sij
Aij = \exp(Sij-mi)\sum_{k=0}^{T_K-1}\exp(Sik-mi)
\sum_{j=0}^{T_K-1} Aij = 1
S = S - np.max(S, axis=-1, keepdims=True)
exp_S = np.exp(S)
A = exp_S / np.sum(exp_S, axis=-1, keepdims=True)
# PyTorch：A = torch.softmax(S, dim=-1)

二维 S 的 axis=-1 就是 axis=1，沿 Key 列归约。每个 Query 有自己的分母，不能对所有元素求一个总和，也不能沿 Query 轴归一化。减最大值把每行最大指数变成 exp(0)=1，其余不超过 1；减去同一个常数不改变这一行的 Softmax 分布。

4. 权重乘 Value，取回内容

H = AV
Hir = \sum_{j=0}^{T_K-1} AijVjr

(T_Q,T_K) @ (T_K,M) 得到 (T_Q,M)。固定 Query i，它的输出向量是 A[i,0]*V[0] + … + A[i,T_K-1]*V[T_K-1]。本例 Query 0 的权重约为 [0.377541,0.622459]，因此更偏向 Value 1。

5. 输出线性投影

O = HWO + bO

W_O 混合 H 的特征，形状仍为 (T_Q,M)。这是线性变换，没有再次做 Softmax：A 是概率分布，H/O 是特征向量。本题 H 是 Value 的凸组合，单个特征位于对应 Value 特征的范围内；经过 W_O 和 b_O 后，O 不再受这一范围约束。

06 / 轴与广播

axis=-1、keepdims=True 与矩阵乘法

1. S[i,j] 的 i、j 分别是谁？

i 沿行变化，指 Query；j 沿列变化，指 Key。固定一行 i，是一个 Query 比较所有 Key；固定一列 j，是所有 Query 分别比较同一个 Key。归一化必须在每个 Query 自己的一行完成。

选择行、列，观察对应位置

2. 矩形更容易看懂 keepdims 的作用

S · (2,3)，最后一轴是 Key
[[1.5, 2.0, 1.0],
 [2.5, 2.0, 1.0]]
axis=0：沿 Query 行
axis=1 / -1：沿 Key 列
max(axis=-1,keepdims=True) · (2,1)
[[2.0],
 [2.5]]
每个 Query 一个最大值
保留列轴，长度变成 1
S - 行最大值 · (2,3)
[[-0.5, 0.0, -1.0],
 [ 0.0,-0.5, -1.5]]
第一行的 3 项都减 2.0
第二行的 3 项都减 2.5

keepdims=True 保留归约轴为长度 1，(2,1) 的每行单值就能广播到 (2,3)。删掉它会得到 (2,)，NumPy 从最后一轴对齐，长度 2 对不上长度 3，会报广播错误。在原题 (2,2) 中反而可能不报错，但会将这两个值分别减到两列，语义错了。

3. np.sum 到底做了什么？

exp_S = np.exp(S)  # 此时 S 已减去行最大值
denominator = np.sum(exp_S, axis=-1, keepdims=True)
# (2,3) → (2,1)：一行的 3 个指数相加成自己的分母
A = exp_S / denominator  # (2,3) / (2,1) → (2,3)

np.sum(exp_S,…) 与 exp_S.sum(…) 等价；np.max(S,…) 与 S.max(…) 等价。np.exp 对每项取指数，/ 是逐元素除法，@ 才是矩阵乘法。没有写 axis 的 np.sum(exp_S) 会把全部元素加成一个标量，不能用于逐行 Softmax。

4. 一个数值对应一条读取路径

原题 Q[0]=[2,0,1,1]，K[1]=[1,1,1,1]，所以 S[0,1]=(2+0+1+1)/2=2。这一行 Softmax 后 A[0,1]≈0.622459，意思是 Query 0 为 Value 1 分配约 62.25% 权重。它不是“输出的第 1 个特征”；真正的输出特征由整个 V[1] 向量提供。

07 / 复现与边界

来源 → 打分 → 行归一化 → 读取 → 输出

Q = ______ @ W_Q + b_Q
K = ______ @ W_K + b_K
V = ______ @ W_V + b_V
d_k = K.shape[______]
S = Q @ ______ / np.sqrt(______)
S -= np.max(S, axis=______, keepdims=______)
exp_S = np.exp(S)
A = exp_S / np.sum(exp_S, axis=______, keepdims=______)
H = A @ ______
O = H @ W_O + b_O
return O.______()
展开答案与自检点
  • Q 用 X_Q；K 和 V 都用 X_K。
  • d_k=K.shape[1]；S=Q@K.T/√d_k。
  • 二维逐行 Softmax：axis=-1 或 1，keepdims=True。
  • H=A@V；返回 O.tolist()。
  • T_Q≠T_K 时 S、A 是矩形，O 行数是 T_Q。
  • T_K=1 时每行权重为 [1]，所有 Query 都读取同一个 V，再经过同一个输出投影。
  • 只改变 X_Q 时 K/V 不变；改变 X_K 会改变可匹配和读取的信息。
  • A 每行和为 1，O 每行无需为 1；大得分应保持有限输出。

时间与空间：两种长度分别出现在哪里？

令 M=d_model。三次输入投影与输出投影合计为 O((T_Q+T_K)M²)；QKᵀ 与 AV 合计为 O(T_Q T_K M)。总时间为 O((T_Q+T_K)M²+T_Q T_K M)，显式注意力矩阵大小为 T_Q×T_K。

本题接口是 Python 列表，转换为数组 / 张量会占用权重副本和中间矩阵，额外空间为 O(M²+(T_Q+T_K)M+T_Q T_K)。原题序列短，适合显式展示；长序列的实际系统可用专用注意力内核减少中间权重矩阵的物化。

两条输入序列不要求长度相同，但不是毫无限制。Q 与 K 的最后一维必须相同才能点积；K 与 V 的 token 数及位置对应必须一致才能读取。通用模型可设置不同的输入维度、d_k 和 d_v，本题则统一为 M；不要把题目简化条件当成所有交叉注意力的固定规则。
