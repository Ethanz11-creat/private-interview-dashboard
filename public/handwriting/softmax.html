P4501. Softmax 计算

难度：5。以下按你提供的题面整理，保留输入输出、示例和全部约束。

题目描述

给定长度为 n 的输入向量 z=[z₁,z₂,…,zₙ]，请实现 Softmax，返回长度为 n 的概率分布向量 p=[p₁,p₂,…,pₙ]。

计算公式

pᵢ = exp(zᵢ)∑ⱼ exp(zⱼ)
稳定形式：pᵢ = exp(zᵢ − max(z))∑ⱼ exp(zⱼ − max(z))

输出满足 Σᵢpᵢ=1，并且 0≤pᵢ≤1。计算时通常采用减去最大值的等价形式，提高数值稳定性。

输入参数

z：长度为 n 的输入向量，元素为浮点数。

返回值

p：长度为 n 的 Softmax 概率列表，第 i 项对应原输入的第 i 项，保持原顺序。

题面示例

输入：
z = [1.0, 2.0, 0.0]

题面给出的输出：
p = [0.2447, 0.6652, 0.0901]
示例的第三项有小的数值偏差：按公式，精确结果约为 [0.2447284711,0.6652409558,0.0900305732]。通常保留四位小数是 [0.2447,0.6652,0.0900]。本页保留题面示例，同时按公式演示；代码返回完整浮点数，不为了凑显示总和而修改最后一项。

数据范围与提示

  • n≥1，输入向量不为空。
  • −100≤zᵢ≤100。
  • 输出概率范围为 0≤pᵢ≤1。
  • 数学上概率总和为 Σᵢpᵢ=1；浮点计算可能出现极小误差。

提交方法是 softmax(self,z)。题目要求概率向量，不要求取最大概率的位置，也没有要求将结果转成字符串。

两个列表推导式里的 x，各代表什么？

[math.exp(x - max_z) for x in z]

x 来自原输入 z。示例中依次是 1、2、0。左侧表达式决定把什么值放进新列表。

[x / sum_exp for x in exp_values]

x 来自指数列表 exp_values，依次约为 0.367879、1、0.135335。它已经不是原始分数。

两处 x 都是循环使用的临时名字；在 Python 3 中，列表推导式的循环变量有自己的作用域。这两处也可以分别改名为 score 和 exp_value，让含义更明显。

05 / 为什么这不是另一个算法

减同一个数，Softmax 的分子分母一起缩放

设 m=max(z)。根据指数规则，exp(zᵢ−m)=exp(zᵢ)/exp(m)，所以每项指数都乘了同一个正的因子 exp(−m)。

pᵢ = exp(zᵢ) × exp(−m)[∑ⱼexp(zⱼ)] × exp(−m) = exp(zᵢ)∑ⱼexp(zⱼ)

共同因子在数学上约掉，因此概率不变。实际上减任意共同常数都不改变数学结果，选最大值是为了让所有指数的输入都不大于 0。

减最大值到底保证了什么？

  • 所有 zᵢ−max(z)≤0。
  • 至少一个差值等于 0，因此至少一个指数是 exp(0)=1。
  • 其他指数在数学上属于 (0,1]，不会向正无穷溢出。
  • 指数总和满足 1≤sum_exp≤n，分母不会为 0。
别混淆“差值”和“指数值”：差值可以为负；exp(负数) 仍是正数。有限实数的指数严格大于 0，但极端浮点下溢可能表示成 0；最大项对应的指数仍是 1，保证整个分母非零。

平移不变：给所有输入加 10

z  = [1, 2, 0]      → max=2  → 差值 [-1,0,-2]
z2 = [11, 12, 10]   → max=12 → 差值 [-1,0,-2]

# 稳定指数列表一致，概率也一致。
题目输入只有 −100～100，会在 Python 中直接 exp 溢出吗？

在 Python 双精度中 exp(100) 仍是有限值，因此这道题范围内的直接指数一般不会产生指数溢出。减最大值仍是 Softmax 的标准稳定实现，更方便处理范围扩大或其他浮点类型的情况。

额外的范围外示例：exp(1000) 会溢出，但输入 [1000,1001,999] 先减 1001，得到 [-1,0,-2]，稳定计算仍有效。它只是解释稳定性的例子，不是本题合法输入。

所有分数相等、只有一个元素，分别会怎样？

所有分数相等时，每项差值是 0，每项指数是 1，总和为 n，所以每个概率都是 1/n。

只有一个元素时，它就是最大值；指数是 1，分母是 1，结果为 [1.0]，与该分数本身大小无关。

原来的分数可以为负，输出为什么仍是概率？

指数将每项转换为正数，除以正的总和后每项非负且不大于 1。分子全部相加等于分母，因此概率总和为 1。

Softmax 和之前神经网络里的 Sigmoid 有什么关系？

Sigmoid 把一个标量映射为标签 1 的概率；Softmax 把一组分数共同转换成一组总和为 1 的概率。Softmax 某一项的概率取决于全部输入分数，因为它们共用分母。

06 / 把简写变成熟悉的循环

两个列表推导式，分别展开

import math

class Solution:
    def softmax(self, z):
        max_z = max(z)

        exp_values = []
        for score in z:
            value = math.exp(score - max_z)
            exp_values.append(value)

        sum_exp = sum(exp_values)

        probabilities = []
        for exp_value in exp_values:
            probabilities.append(exp_value / sum_exp)

        return probabilities

这里特意把第一个循环变量叫 score，第二个叫 exp_value。与原版的 x 只是名字不同，计算完全一样。

复杂度：四次线性操作，仍然是 O(n)

步骤时间存储
max(z)O(n)max_z 是一个标量，O(1)。
创建 exp_valuesO(n)保存 n 个指数，O(n)。
sum(exp_values)O(n)sum_exp 是一个标量，O(1)。
创建返回列表O(n)返回 n 个概率，O(n)。

总时间约为四个线性步骤之和，忽略常数后是 O(n)。额外空间是 O(n)：即使不计返回列表，exp_values 也保存了 n 个元素。

复习之前的空间复杂度问题：临时变量 x 每次只代表一个数，是 O(1)；但是列表推导式会把每次产生的结果保留下来，累计成 n 个存储位置，是 O(n)。不能因为“循环变量只有一个”就把新列表也算作 O(1)。
07 / 看懂后自己写

四行口诀：最大值、指数表、指数和、除总和

复盘 1：max 返回下标吗？

z=[1,2,0]。

查看答案
max(z)=2，是最大值；它的位置是下标 1，但这题用的是最大值。

复盘 2：第一条列表推导式里的 x？

[math.exp(x-max_z) for x in z]

查看答案
x 依次是原输入的 1、2、0；生成的新列表元素是 exp(-1)、exp(0)、exp(-2)。

复盘 3：分母能不能用 sum(z)？

查看答案
不能。分母必须是指数列表的总和 sum(exp_values)，与原分数总和不同。原分数之和还可能是 0 或负数。

复盘 4：只剩一个输入 −100 呢？

查看答案
减最大值后是 0；exp(0)=1，分母也是 1，返回 [1.0]。

常见错误对照

容易写错的地方应该记什么
把 max 当成位置这里用 max(z) 的值，拿它做共同平移。
指数写成 exp(max_z−x)应是 exp(x−max_z)，反过来会改变大小关系。
最后遍历 z 再除总和最后遍历 exp_values，分子必须是指数。
使用 // 除法使用 /，保留浮点概率。
为了显示四位小数提前 round计算与返回保留完整浮点数；只有展示时格式化。
先对 z 排序无需排序，输出顺序对应原输入。
面试口述：“我先找到输入最大值，让每个分数减去它再求指数，避免大的正指数。所有项共同平移不会改变 Softmax，因为分子分母的共同指数因子能约掉。接着求指数总和，每项除以总和得到概率。时间 O(n)，保存指数列表和输出列表需要 O(n) 空间。”
