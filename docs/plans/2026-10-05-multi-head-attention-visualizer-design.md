# Multi-Head Attention 张量维度可视化设计

## 目标

让页面把“一个 token 的 `d_model` 特征如何分给多个 head、每个 head 如何独立计算、最后如何拼回完整特征”讲成可以逐步点击的张量流水线，重点对应截图中的 `reshape`、`transpose`、批量矩阵乘法、`softmax(dim=-1)` 和拼接代码。

## 设计

- 在现有“拆头与换轴”板块中加入独立的交互式可视化，不删除原有静态解释和真实数据演示。
- 固定使用 `T=2、d_model=4、h=2、d_k=2` 的小矩阵，让每个单元都能追踪；用颜色区分 head 0、head 1、注意力权重和拼回后的矩阵。
- 依次展示完整 Q/K/V、`reshape(T,h,d_k)` 分组、`transpose` 换成 `(h,T,d_k)`、每头的 `(T,T)` 得分、`softmax(dim=-1)`、各头输出、换轴后拼回 H，以及输出投影 O。
- 每一步同时显示代码、输入/输出形状和语义说明；下方增加截图代码的形状对照表与面试口述版本。
- iPad 9 宽度下使用两列或纵向堆叠的卡片，步骤按钮可横向滚动；桌面端保留多卡片并排的流程感。

## 实现边界

- 新增 `public/handwriting/multi-head-visualizer.js`，页面加载后将演示 DOM 与局部样式插入 `#axes` 标题之后。
- 可视化采用小矩阵帮助建立直觉；原有交互演示继续负责切换数据集和 `h=1/2/4` 的真实数值对照。
- 不引入 batch、mask、dropout、残差或层归一化，保持与题干当前简化前向计算一致。

## 验证

- 新增脚本和页面内嵌脚本 `node --check`。
- `npm run check` 与 `git diff --check`。
- 本地浏览器依次点击拆头、换轴、得分、Softmax、拼头步骤，核对形状和值；在 810px 和窄屏视口下检查无页面级横向溢出。
