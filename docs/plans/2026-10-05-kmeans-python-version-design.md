# K-Means 双版本逐行解析

在现有 K-Means 页的「逐行拆解」顶部加入 NumPy / 纯 Python 两个切换按钮。默认保留 NumPy，切换时同步更新完整代码、行号、逐行说明、上一行 / 下一行和复制内容；各版本保留本次阅读的选中行和代码滚动位置。

纯 Python 版本只依赖标准库类型标注，用列表、双层循环计算最近中心，并用坐标和与计数更新均值。与已有 NumPy 版本遵循同一题面：前 k 个点初始化、相同距离优先较小簇编号、空簇保留旧中心、标签不变提前停止、仅输出时保留四位小数。输入坐标不被修改。

既有题干、NumPy 逐行解释、广播演示和聚类示例全部保留；在复杂度说明中补充纯 Python 版本不构建 n×k 距离矩阵、额外空间为 O(n+k)。按钮适配触屏与 iPad 阅读模式，使用原生按钮和 aria-pressed 表示选择状态。

验证两份复制代码的语法、原题示例、单簇、重复中心、空簇、等距、迭代上限及输入不变；在浏览器验证切换、阅读位置恢复、导航边界和复制内容，并检查 iPad 9 横竖屏。通过后更新现有 GitHub Pages。
