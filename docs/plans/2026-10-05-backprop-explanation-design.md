# 反向传播逐行讲解重组

在 P4486 反向传播页面前置一个总览板块，先把“前向得到 loss、反向沿相反方向使用链式法则”建立成整体模型，再进入原有题干、代码逐行点读、数值演示和数值保护。总览使用 SVG 展示前向链、反向链和从 z2 / z1 分叉出来的参数梯度，适配 iPad 宽度并保留独立横向滚动。

总览后的八步路线依次解释概率 clip、BCE、Sigmoid+BCE 的 δ2、输出层梯度、传回隐藏层、ReLU 掩码、外积 dW1 和统一参数更新。三个问题卡片分别回答：−log 与 BCE 的关系、为什么 dW1 必须用 x 与 δ1 的外积、dL_dz2=ŷ−y 能否直接记以及适用前提。

现有 NumPy / Torch 逐行数据不删除，只对 y_hat_clipped、BCE、dL_dz2、dW2、dL_dh、ReLU 掩码、dW1 和 db1 的解释做补强。特别说明 clip 只保护概率形式的 loss，极端 logit 应使用 BCE-with-logits；解释 dW1[i,j]=x[i]δ1[j] 与 W1 形状一致；强调 dL_dz2=ŷ−y 只适用于 Sigmoid+BCE 组合。

验证页面内嵌脚本、项目检查、链路图 DOM、三张问题卡、逐行点击后的增强解释，并在 810px 宽度下检查没有页面级横向溢出。完成后提交并部署 GitHub Pages。
