# 面试手册阅读体验优化

用户已授权按 ui-ux-pro-max、frontend-design、ego-browser 的建议直接优化并发布。沿用白底蓝色结构，采用编辑式手册风格，全部正文保留。

## 设计决策

- 浅灰绿外层、白纸正文、深蓝章节线；以字体、留白和轻分隔建立层级，减少嵌套边框。
- 标题使用本地宋体/衬线字体，正文使用 Avenir Next / 苹方 / 微软雅黑，编号使用等宽字体。无需外部字体服务。
- 正文 15px、细节 14px、节标题 18—24px、页面标题 34px；大字阅读提升到 17/16px，窄屏正文默认 16px。
- 左侧持续可达，右侧支持主题标题过滤、空结果提示、收起目录和当前位置，正文不参与搜索隐藏。
- 三栏宽屏、双栏中屏、手机页签及弹出目录。按正文容器宽度决定内容是否两列，图表保留完整内容并局部横向滚动。
- 辅助措施：跳到正文、键盘焦点、44px 手机点击区域、动画减弱、URL 恢复、大字偏好本地保存失败时仍可使用。

## 文件范围

新增 reading-design.css；更新页面外壳和 topic-navigation.js；构建脚本与所有项目正文保持原样。读取 ui-ux-pro-max 的对比度、排版、键盘、触摸和搜索空状态建议。

## 验证

比对四页渲染正文摘要及源模板；四页导航、标题搜索、空结果、清空、展开收起、字号保存、刷新深链；桌面/中屏/手机截图和横向溢出；发布后核对线上文件与本地一致。

### 本地验证结果

- `npm run build`、`npm run check`、两个内联脚本语法检查和 `git diff --check` 通过。
- `projectSource`、`supervisorSource` 两个源模板与修改前逐字一致。
- 四页 `#app.textContent` 的 SHA-256 与修改前完全一致：业务面 82,052 字符、八股题库 10,442 字符、主管面 5,644 字符、HR 面 24,203 字符（包括原有空白）。
- 浏览器验证 1512px、1000px、390px、320px 布局；四页桌面及手机截图、记忆生命周期图、Function Calling 通栏图、五险一金手机表格已实际查看。页面无横向溢出，宽图表保留块内滚动。
- 验证主题搜索“记忆”“Function”“薪资”“五险”、父主题匹配、无结果、Esc 清空及关闭、收起目录、返回顶部、隐藏章节自动展开、跨页和浏览器后退、深链刷新。
- 大字阅读将 HR 答案从 15px 提升到 17px，偏好可跨页面和刷新保存。目录搜索不隐藏任何正文；清空后保留当前阅读位置的目录路径。
