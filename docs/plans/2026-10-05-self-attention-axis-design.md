# Self-Attention 的 axis / keepdims 矩阵演示设计

## 目标

把 `S = S - np.max(S, axis=1, keepdims=True)`、`np.exp(S)` 和 `np.sum(..., axis=1, keepdims=True)` 从纯文字说明变成可以逐步点击的矩阵变化演示。页面需要同时解释 `axis=1` 的方向、归约后的形状、NumPy 广播，以及稳定 Softmax 的最后一步按行归一化。

## 设计

- 在 Self-Attention 的 `axis 与广播`板块中增加独立的矩阵实验，不删除已有正文和静态示例。
- 使用 `S=[[1,2,3],[4,5,6],[7,8,9]]`，依次展示原始矩阵、每行最大值、`keepdims=True` 的列向量、广播相减、逐元素 `exp`、每行指数和、按行归一化后的 `A`。
- 每一步同时展示代码、输入/输出形状、矩阵数值、操作说明和上一步/下一步按钮；补充 `(3,)` 与 `(3,1)` 的并列对照及语法速记表。
- 通过颜色区分原始矩阵、列向量、平移后分数、指数和注意力权重；矩阵卡片在窄屏下堆叠，步骤按钮保持可横向滚动。

## 实现边界

- 新增 `public/handwriting/axis-visualizer.js`，由页面加载后插入演示 DOM 与局部样式。
- 保留原有 NumPy / PyTorch 逐行拆解、真实 Self-Attention 数值演示和静态广播示例，不改动其他手撕页面。
- 该演示使用固定小矩阵帮助建立直觉，真实题目中的 `n`、`d` 仍由原有代码和数值演示说明。

## 验证

- `npm run check`
- 内嵌脚本与新增脚本 `node --check`
- `git diff --check`
- 本地浏览器逐步点击矩阵演示，核对每一步数值和形状；在 810px 视口下确认无页面级横向溢出。
