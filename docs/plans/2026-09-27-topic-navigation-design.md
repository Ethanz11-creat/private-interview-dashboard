# 四个面试页面的主题导航

用户要求在最右侧增加当前页主题导航，快速定位不断增长的资料。保留全部正文，沿用蓝白阅读样式。

- 桌面三栏：轮次、完整正文、独立滚动的粘性主题目录。
- 业务面按项目、速答区、深挖章节分层；八股按分类与题目；主管面与 HR 面按主题与问题。
- 根据最终渲染的标题生成目录，切换轮次自动重建，不维护正文副本。
- 目录分组可收放，正文展示方式不变；跳转到折叠正文时先展开目标父级。
- 滚动同步当前位置，点击直接定位，顶部固定栏不会遮住标题。
- 窄屏使用右下角目录按钮，支持关闭、Escape 和键盘焦点；桌面正文与目录互不覆盖。
- 轮次写入 URL 参数，主题使用稳定锚点，支持刷新后继续阅读。
- 验证四个页面切换、嵌套标题、折叠正文跳转、滚动定位、窄屏与线上发布；核对正文保留。
